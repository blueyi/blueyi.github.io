1️⃣ AI 芯片

  • theregister.comMeta reuses old RAM in new servers with custom bridge chip 🔥
    (HN 294 分) — Meta 定制了一颗 CXL 桥接 ASIC,把老服务器上退役下来的 DDR4 内存"回收"到新一代服务器里,以 CXL memory pool 的形式挂到新平台上。在 HBM/DRAM 价格全线暴涨的当下,自研桥接 ASIC + 二手 DRAM 复用是超大规模厂省钱的典型硬件路线,给国内二线云厂做 CXL memory expander 也提供了强背书。
  • arxiv.orgMemory Scarcity, Open Models, and the Restructuring of the AI Industry, 2026-2030 🔥
    — 定量情景分析:DRAM/HBM 价格飙升 + 前沿开源权重(GLM-5.2) + 近 Shannon 极限的 KV cache 压缩 + Meta/xAI 进入算力转售,四力将在 2026-2030 重塑 AI 产业格局。作者以"美元/PB·s"为单位重构推理经济学,并给出训练成本发散与基础设施偿付能力的分歧曲线,对芯片采购和产能规划有直接参考价值。
  • arxiv.orgMultiple Double Arithmetic on NVIDIA Tensor Cores
    — 把 multiple-double(多重双精度)算法映射到 Ampere A100 起的 FP64 tensor core 上。难点是 renormalization 需要分支,而 tensor core 不擅长分支,论文给出无分支的规约算法,对科学计算类 workload 在 GPU 上的高精度加速有价值。
  • arxiv.orgThermoDSE: Thermal-Aware DSE for Chiplet-Based DNN Accelerators
    — 面向 chiplet 化 DNN 加速器的热感知设计空间探索框架,联合考虑任务建模、chiplet 粒度、core 粒度与热约束。是首个把物理约束与 fine-grained task 建模一起纳入 DSE 的工作,对下一代 UCIe 时代的 AI 芯片设计有借鉴意义。

2️⃣ AI 编译器与框架

  • arxiv.orgFinding and Understanding Miscompilation Bugs in the Solidity Compiler
    — 语义感知的差分 fuzz 工具 SolSmith,三年时间在 Solidity 编译器里挖出大量 miscompilation。虽然领域在智能合约,但方法学(semantics-aware differential fuzzing)完全可以搬到 MLIR / TVM / XLA 上做 tensor 编译器验证。

    — 提出 Virtual Tensor 抽象,统一 layout transform 与 operator fusion,把数据搬运优化扩展到更大的算子子集。当代 DNN workload 里 compute 与 memory 延迟差距越来越大,VTC 这类跨算子数据搬运消除会成为编译器主流手段。
  • arxiv.orgLFPL: Revisited and Mechanized
    — Hofmann 1999 年的 LFPL 语言(用仿射类型刻画多项式时间可计算函数)被重新机械化证明。看似纯理论,但线性/仿射类型系统正是当代 Rust-like GPU DSL 与自动内存管理编译器的理论基石。
