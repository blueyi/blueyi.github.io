    摘要把记忆定义成对历史的有偏重构——无论人脑还是长周期智能体，一旦建立记忆，原始交互就会被提炼、合并、更新和遗忘，重新编成不同层级。标题指向一个反直觉结论：更复杂的记忆未必赢过直接检索原文。Agent 的推理成本不能只按生成 token 计，记忆的写入、合并和召回是一笔不一定买来正确率的税。来源
  • aiera.com.cn「缓存税」被拿来解释 Anthropic 的利润结构
    新智元援引开发者圈讨论（包括 Java Champion Vlad Mihalcea 的帖子），把提示缓存计费称作 Anthropic 的「缓存税」。推理优化过去把缓存当成纯技术胜利：命中前缀就能少算。一旦命中本身成为定价项，命中率上升、算力下降，账单却未必下降。优化目标会从少算 FLOPs 改成在计费规则下少付钱。来源
  • philippdubach.com杰文斯悖论：更便宜的 token 付不起资本开支
    HN 71 分。文章标题直接否定「降价就能做大用量、用量就能覆盖机房资本开支」这条链条。量化、缓存和投机解码都在把单 token 成本往下打；若用量放大填不上已签约的电力、GPU 和厂房，便宜本身会变成收入缺口。来源
