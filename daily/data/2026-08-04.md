## 1️⃣ AI 芯片

- [Characterizing LLM Kernel Access and Memory Interaction in Multi-Partition NUMA GPUs](https://arxiv.org/abs/2607.28824) — 系统分析LLM核心kernel(weight projection / MoE / attention)在多分区NUMA GPU上的访存模式与跨分区通信瓶颈，揭示非均匀内存架构下的性能退化根因，为下一代GPU互连与缓存设计提供量化依据。
- [Selective KV Cache Protection for Noise-Resilient LLM Inference on Analog Compute-In-Memory Systems](https://arxiv.org/abs/2607.29076) — 提出选择性KV Cache保护策略，解决模拟存算一体(CIM)阵列在attention计算中因频繁权重重写与weight-stationary范式不匹配引入的噪声问题，为模拟CIM芯片部署LLM推理扫清关键障碍。

## 2️⃣ AI 编译器与框架

- [Octane – React's programming model, compiled](https://octanejs.dev) (HN 118分) — 将React声明式编程模型编译为高效原生代码的编译器框架，借鉴AI编译器中的图优化与代码生成思路，将组件树转为可直接执行的优化指令序列。
- [Testing, Credible Compilation, and Verification in the Axon Verified Compiler in Lean and Claude Code](https://arxiv.org/abs/2605.01660) — Axon验证编译器完全由Claude Code在Lean中编写并机器验证，实现从编译器到生成代码的全链correctness proof，消除了对验证代码的人工审计需求。
- [High-Level Big Integer Arithmetic in Futhark for GPUs](https://arxiv.org/abs/2607.28897) — 用函数式语言Futhark在GPU上实现2^15~2^19比特大整数算术的高层编译，识别哪些函数式构造可高效映射到CUDA，为高层语言在数值密集型GPU计算的编译优化提供实践指南。
- [From C to Idiomatic Rust: A Ship-of-Theseus Agentic Translation](https://arxiv.org/abs/2607.28835) — Agent驱动的C→Rust翻译框架，采用"忒修斯之船"渐进式替换策略（参见分类7）。

## 3️⃣ AI 推理优化(数据中心)

- [DeltaServe: Host-Agnostic Co-Serving of Inference and Fine-Tuning for LLMs](https://arxiv.org/abs/2607.28848) — 提出与主机无关的推理+微调协同服务设计，将峰值推理的空闲GPU算力转化为LoRA微调吞吐，在保障推理SLO的前提下提升集群整体利用率。
- [SLIM: Saturation-Aware Lightweight Performance Modeling for LLM Serving](https://arxiv.org/abs/2607.29575) — 揭示LLM推理性能饱和不仅受限于HBM带宽，更与部署相关的batch size天花板有关，提供轻量级饱和感知建模以避免无效扩容。
- [Topology-Aware Data Movement for Disaggregated GPU Inference](https://arxiv.org/abs/2607.28633) — 指出现有分离式推理系统(DistServe/Splitwise/Mooncake)均忽略GPU池间网络拓扑异构性，提出拓扑感知的KV Cache传输策略——70B模型每请求2.6GB KV迁移可大幅降低跨池延迟。
- [LARA: Lightweight Adapters in the Residual Stream for Composable Adaptation](https://arxiv.org/abs/2607.28669) — 在残差流(而非权重矩阵)中注入低秩修正的轻量适配方法，冻结base model全权重，实现可组合的模型适配与对齐。
- [Hierarchical Copula-Gumbel-Top-K Routing for MoE](https://arxiv.org/abs/2607.28670) — 为MoE模型提供保持逐token路由律不变的两侧依赖控制，在固定单token路由分布下灵活建模token间联合路由选择。

- [CARA: Exact Local Repair with Fresh One-Action Certification for Cloud Consolidation](https://arxiv.org/abs/2607.29465) — 提出证书对齐重组方法，为云资源整合中的布局修复提供可证明的单步认证保证。

- [D-VLC: Decentralized Vision-Language Collaboration for Heterogeneous Multi-Robot Systems](https://arxiv.org/abs/2607.29009) — 去中心化VLM协作框架，使异构多机器人系统在未知环境中通过自然语言指令实现协同任务执行。

- [DART: Dual-Axis Airborne Reachability-Gated Torque-Reaction for Off-Road Vehicle Jumps](https://arxiv.org/abs/2607.29011) — 越野车辆跳跃空中姿态控制：利用车轮角动量预算在1.4吨平台上实现约9~13°/s俯仰修正，降低着陆碰撞风险。

## 8️⃣ 边缘与端侧推理
