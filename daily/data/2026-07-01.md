## 1️⃣ AI 芯片
- 🔥 [三星、SK 海力士、美光在美遭起诉,涉内存价格操纵](https://en.sedaily.com/international/2026/06/29/samsung-sk-hynix-micron-sued-in-us-over-memory-price-fixing)(HN 419 分):三大 DRAM/HBM 供应商被指控合谋操纵内存价格。在 HBM 供不应求、AI 训练集群疯抢显存的当下,这一诉讼若成立可能重塑内存定价格局,直接牵动整个 AI 硬件成本曲线。

## 2️⃣ AI 编译器与框架
- [KoAT:整数程序自动复杂度与终止性分析](https://arxiv.org/abs/2606.28542):以模块化交替推断上界运行时与规模界,组合多种技术分析子程序,面向(含递归)整数程序做复杂度证明,是编译器静态分析工具链里的实用基础件。
- [Symbolon:通过学习代码变换做符号执行](https://arxiv.org/abs/2606.29108):针对符号执行的路径爆炸与复杂约束瓶颈,用学习到的代码变换规避特定结构/语义模式,提升可扩展性——程序分析与 AI 结合的新尝试。
- 背景补充:tinygrad / MLIR / TVM / Triton / Mojo 近两天无重大独立发布,主流框架进入常规迭代期。

## 3️⃣ AI 推理优化(数据中心)
- 🔥 [LongCat-2.0:1.6T 总参 / 48B 激活的大规模 MoE 模型](https://longcat.chat/blog/longcat-2.0/)(HN 268 分):超大规模稀疏 MoE 通过激活参数占比极低来平衡训练/推理成本,是当前"万亿总参、几十 B 激活"路线的又一次落地,对 MoE 服务化与专家路由调度提出新要求。
- [KernelFlume:面向 Agentic 长上下文解码的弹性 Core-Attention 扩缩](https://arxiv.org/abs/2606.29207):针对 Agent/推理模型带来的长且动态的 decode 负载,不再靠"再复制一份完整模型副本"来扩容 KV 容量,而是做 attention 层级的弹性扩展,直击长上下文服务的 KV 成本痛点。
- [Micro-Agent:在模型 API 内用协作击败前沿模型](https://vllm.ai/blog/2026-06-29-micro-agent-frontier-models)(HN 77 分):vLLM 团队提出在推理服务内部编排多智能体协作,以较小模型组合逼近前沿模型能力——服务层与 Agent 编排融合的新范式。
- [Tri-serve:能效导向的多模态推理服务](https://arxiv.org/abs/2606.29629):发现 GPU 板载 PMU 的自主频率升降决策会造成显著功耗低效,提出针对多模态推理的三类功耗优化,兼顾性能与能效。

## 4️⃣ 数据中心与基础设施
- 🔥 [坐拥 37 座数据中心的县,反过来要求学校"节约用电"](https://www.404media.co/henrico-virginia-datacenter-energy-cost-email/)(HN 388 分):弗吉尼亚 Henrico 县因数据中心电力挤占,竟向学校发邮件要求节电。AI 基础设施 capex 狂飙下,电网承载与社区用电冲突正从"隐忧"变成"现实账单",是数据中心电力叙事的标志性事件。
- [HBM Is Not All You Need:跨异构内存加速器的高效解耦式 LLM 服务](https://arxiv.org/abs/2606.29986):prefill 计算受限、decode 内存受限,而昂贵 HBM 的带宽在 prefill 阶段几乎闲置;该工作用 GDDR 加速器跑 prefill、HBM GPU 跑 decode,提出内存异构(MemHA)服务方案,兼顾成本与性能。
- [硬盘可靠性存在厂商差异吗?](https://arxiv.org/abs/2606.29078):基于 Backblaze 数据集,控制驱动年龄/容量/形态/温度后用两种时长回归模型分析 HGST/Seagate/Toshiba/WD 的失效率差异——数据中心存储选型的实证参考。

## 6️⃣ 具身智能
- [RoboGaze:用结构化视觉-语言分析评测机器人世界模型](https://arxiv.org/abs/2606.28385):合成视频常视觉逼真却违反物理定律/时序一致性,传统指标与单体 VLM 评判难以泛化,RoboGaze 提供更精细的诊断价值。
- [The Speedup Paradox:重思具身任务中推理速度-质量的权衡](https://arxiv.org/abs/2606.28529):量化/剪枝/异步推理带来的微小动作质量下降,在具身场景中未必是"划算的交易"——挑战了"牺牲精度换低延迟"的惯常假设。
- [FADA:通过动力学对齐做少样本域适应的人形控制](https://arxiv.org/abs/2606.28476):针对地形/负载/执行器响应变化导致的动力学失配,以少样本适应实现高精度人形控制,避开域随机化与重型适应管线的两难。
- 另有 [被动物体状态世界模型的事件条件诊断](https://arxiv.org/abs/2606.28455)、[近端主动性对群体人机协作的影响](https://arxiv.org/abs/2606.28469)、[自动驾驶查询驱动的通信高效数字孪生](https://arxiv.org/abs/2606.28384) 等,世界模型评测与人机协作是本日热点。

## 7️⃣ AI 自动算子与代码生成优化
- [证据驱动的 LLM Agent 做 C→可综合 C 转换与验证](https://arxiv.org/abs/2606.28409):软件可编译的 C 常无法通过 HLS 四阶段流水线(编译/CSim/综合/CoSim),该 Agent 覆盖完整流水线并回喂证据修复,是 LLM 驱动硬件设计/RTL 生成方向的代表作。
- [KernelSight-LM:内核级 LLM 推理模拟器](https://arxiv.org/abs/2606.28565):把服务层策略与底层 GPU kernel 执行耦合建模,让实践者无需慢速的部署特定基准就能快速评估跨硬件/模型/服务参数的推理性能——算子级性能建模与自动调优的利器。
- 背景补充:AlphaEvolve / FunSearch 类"AI 自动发现算子"近两天无新公开进展,当前热点集中在 LLM 驱动的 HLS/RTL 修复与内核级仿真。

## 8️⃣ 边缘与端侧推理
- 🔥 [Nano Banana 2 Lite(Gemini Image Flash-Lite)](https://deepmind.google/models/gemini-image/flash-lite/)(HN 294 分):DeepMind 推出更轻量的图像生成模型,主打低延迟/低成本,契合端侧与轻量化部署趋势,是"小而快"路线在多模态生成上的落地。
- [COSM:移动设备上 PIM 与 CPU 并发执行的协同调度框架](https://arxiv.org/abs/2606.30553):面向端侧 LLM 的隐私与响应速度需求,用存内计算(PIM)缓解移动端高能耗数据搬运,并在严苛 DRAM 成本约束下做 CPU-PIM 协同调度——端侧硬件-软件协同的硬核工作。
- [边缘 AI 计算的通用近似收割](https://arxiv.org/abs/2606.29518):边缘 AI 芯片常因时空冗余而利用率不足、算力浪费,该工作用通用近似"收割"被闲置的边缘算力。
- [RQP:面向 FPGA 神经网络的资源导向量化器剪枝](https://arxiv.org/abs/2606.30382):基于高粒度量化(HGQ)做权重级量化+剪枝,面向 FPGA 边缘 NN 应用,在精度与硬件利用率间取得优良权衡。
- 另:[Zluda 6 发布,让未修改的 CUDA 应用跑在非 Nvidia GPU 上](https://vosen.github.io/ZLUDA/blog/zluda-update-q1q2-2026/)(HN 141 分),虽偏兼容层,但对打破 CUDA 锁定、拓宽端侧/异构硬件生态有长期意义。
