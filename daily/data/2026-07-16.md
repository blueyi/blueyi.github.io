## 1️⃣ AI 芯片
- [FPGA-Based Mini X-Ray Detector Front-End](https://arxiv.org/abs/2607.12126):医疗影像前端电子学的 FPGA 实现,强调大数据吞吐下可预测时序与低延迟采集,是"传感器+加速器"融合的边缘硬件样本。
- [ORRAM: An OpenROAD-Integrated RAM Generator Using Standard Cells](https://arxiv.org/abs/2607.12244):在开源 EDA 流程 OpenROAD 中用标准单元生成 RAM,绕开 PDK 专用存储编译器的依赖,对开源芯片/turnkey ASIC 流程是实用一步。
- [CLIP-3D: Closed-Loop Evaluation of Performance and Physical Constraints for 3D ICs](https://arxiv.org/abs/2607.12788):把 gem5 的理想 IPC 与 3D IC 真实布局(热点、功耗图、cache 几何)闭环耦合,给堆叠芯片设计提供更贴近物理的吞吐评估。
- [A 32-channel event-based bio-signal analog front-end](https://arxiv.org/abs/2607.12901):32 通道事件驱动模拟前端 ASIC,双模编码,面向低功耗神经形态生物信号处理,端到端事件式采集的代表设计。

## 2️⃣ AI 编译器与框架
- 🔥 [Codex Micro](https://openai.com/supply/co-lab/work-louder/)(HN 257):OpenAI 联合硬件推出 Codex 相关的实体设备/工作流产品,代码智能体正从纯软件向物理外设延伸,值得关注其对开发者工具链的整合方式。
- [Bidirectional Type Slicing](https://arxiv.org/abs/2607.12197):为双向类型系统提出"类型切片",不仅告诉你表达式是什么类型,还能给出重现该类型所需的最小程序切片,对类型驱动的 IDE/编译诊断有直接价值。
- [Foundational Constraint Solving for Expressive Refinement Typing](https://arxiv.org/abs/2607.12226):在 LEAN 中实现的 CHC 求解器 FLEX,缩小验证器可信基础,兼顾表达力与可信度,是 SMT 驱动验证工具链的底层加固。
- [Rzk: a Proof Assistant for Synthetic ∞-Categories](https://arxiv.org/abs/2607.12207):面向有向类型论的证明助手,推进合成 ∞-范畴的机械化推理,属编译器/类型论前沿基础设施。

## 3️⃣ AI 推理优化(数据中心)
- [FlashDiff: Efficient Regional Execution and Scheduling for Diffusion Model Serving](https://arxiv.org/abs/2607.12121):针对扩散模型"全区域反复更新"导致的高延迟,提出区域化执行与调度,提升多 GPU 服务吞吐,是图像/视频/音频生成服务化的关键优化。
- [How Query Visibility Changes KV-Cache Compression Rankings](https://arxiv.org/abs/2607.11942):指出 KV-cache 压缩多在"query-aware"下评测,而真实复用场景需 query-agnostic 压缩;等预算审计发现方法排名会翻转,对压一次答多问的部署很有指导意义。
- [Semidirect Fourier Delta Attention](https://arxiv.org/abs/2607.11897):用块旋转 Fourier 控制替代实对角衰减,增强线性注意力的精确状态跟踪与长上下文记忆,兼顾固定循环状态的效率。

## 4️⃣ 数据中心与基础设施
- 🔥 [Mysteries of Telegram Data Centers (2022)](https://dev.moe/en/3025)(HN 240):对 Telegram 数据中心分布与运作方式的深挖,虽为旧文重新走红,但对理解超大规模消息服务的基建拓扑仍有参考。

- [Decentralized Gradient Descent: Bottleneck Regimes and Budget Complexity](https://arxiv.org/abs/2607.12172):从资源视角刻画去中心化梯度下降的通信-计算预算复杂度,对分布式训练的网络/算力规划有理论支撑。
- [Parallelizing Legacy Mesh Generation Software (AFLR)](https://arxiv.org/abs/2607.12253):以黑盒方式并行化遗留网格生成软件,数据分解+运行时负载均衡,HPC 遗留代码并行化的实战经验。

## 6️⃣ 具身智能
- [LeMario: Training a JEPA World Model on Super Mario Bros](https://www.benjamin-bai.com/projects/lemario)(HN 129):在超级马里奥上训练 JEPA 世界模型,世界模型/自监督表征的可玩性演示,直观展示预测式表征学习。
- [EFLUX: Elastic Multi-Robot Formation Navigation with Agentic LLMs](https://arxiv.org/abs/2607.12050):多机器人在拥挤环境中用 agentic LLM 实现队形变形与拓扑重构,兼顾连通性与分裂/合并,群体机器人导航的新范式。
- [GaitSpan: Growing Humanoid Locomotion from Walking to Running](https://arxiv.org/abs/2607.12114):让人形机器人从走到跑无需从零重学,支持连续速度指令与多地形的柔性泛化,摆脱固定步态调度。
- [Robust In-Hand Manipulation via Priors in RL and Mechanical Design](https://arxiv.org/abs/2607.12105):用两类物理先验实现无外部传感的稳健手内滚动操作,维持良态抓取,真机灵巧操作的实用进展。
- [More than a Manipulator: Propellant-Free Attitude Maneuvers for Spacecraft](https://arxiv.org/abs/2607.12130):把机械臂运动当作航天器姿态执行器而非扰动源,实现无燃料姿态机动,空间机器人控制的巧思。

## 7️⃣ AI 自动算子与代码生成优化
- [Contract-Grounded Behavior Tree Synthesis via Coding Agents](https://arxiv.org/abs/2607.12220):用编码智能体从自然语言合成机器人行为树,并以契约保证只引用可执行技能,降低部署脆性,是 LLM 生成可部署代码的落地思路。
- [GRID: Grammar-Railed Decoding for Enterprise SQL Generation](https://arxiv.org/abs/2607.11951):语法约束解码保证企业级 SQL 生成语法有效、符合角色/模式策略并留合规记录,LLM 代码生成加"护栏"的代表工作。
- [Mystra: Declarative Dynamic Taint Analysis via Shadow Virtual Machine](https://arxiv.org/abs/2607.12308):用影子虚拟机解耦污点分析的观测/传播/状态维护,声明式定义传播规则,降低解释型语言 DTA 的开销与引擎耦合。

## 8️⃣ 边缘与端侧推理
- 🔥 [Running Gemma 4 26B at 5 tokens/sec on a 13-year-old Xeon with no GPU](https://www.neomindlabs.com/2026/06/08/running-gemma-4-26b-at-5-tokens-sec-on-a-13-year-old-xeon-with-no-gpu/)(HN 221):在 13 年前的无 GPU Xeon 上纯 CPU 跑 Gemma 4 26B 达 5 tok/s,展示极致量化+老硬件的端侧推理可行性,是"人人可本地跑大模型"的生动案例。
- [HeteroMosaic: Heterogeneous Execution for Energy-Efficient Edge LLM Inference](https://arxiv.org/abs/2607.12839):在 CPU+iGPU+NPU 统一内存 SoC 上做细粒度设备放置与任务图协调,挖掘异构资源以提升边缘 LLM 能效,直击当前 runtime 粗粒度决策的痛点。
- [CARE-LoRA: Compressed Activation REconstruction for Memory-Efficient LoRA](https://arxiv.org/abs/2607.11940):通过压缩激活重建降低 LoRA 微调显存占用,让在有限内存设备上适配大模型更可行,端侧/受限环境微调有用。
- [Realizable N:M Sparse Transformer Inference via Search-Kernel Co-Design](https://arxiv.org/abs/2607.12505):针对 ViT 的 N:M 半结构化稀疏,通过搜索与内核协同设计把理论 FLOPs 节省真正转化为端到端加速。
