# 📡 AI Infra 日报 · 2026-08-22(周六)

> 覆盖窗口:2026-08-20 ~ 2026-08-22 · 信息源:Hacker News / arXiv

## 1️⃣ AI 芯片
- [HyperCut](https://arxiv.org/abs/2608.19296):面向 tiled 加速器的 DNN 层间调度,用有向超图建模 + 早过滤机制,替代"先做细粒度层内调度再反馈成本"的低效路径,在规模化 DNN 上显著提升计算资源利用率与能效。
- [HYDRA](https://arxiv.org/abs/2608.19395):针对动态混合 Transformer-Mamba LLM 负载的异构 Chiplet 设计空间探索框架,把静态架构配置与动态运行策略纳入统一搜索,解决混合架构计算/通信模式异构带来的加速难题。
- [异构 HBM 多态可靠性](https://arxiv.org/abs/2608.19471):建立精确多态可靠性框架,刻画 HBM 服务单元"满速/降速/隔离"等部分服务状态,并给出基于阈值剪枝 BAT 的升级设计方案。
- [AmpereOne CPU 核性能验证](https://arxiv.org/abs/2608.19300):公开覆盖四代 AmpereOne 定制核的工业级性能验证方法论,核心是 RTL 设计与 trace-driven 参考模型的周期精确对齐,面向 pre-silicon 阶段。
- [线程-寄存器解耦的 GPU 执行模型](https://arxiv.org/abs/2608.19628):解耦线程与寄存器调度,适配从 Ampere 寄存器式到 Hopper/Blackwell 内存式 Tensor Core 操作数供给的演进,优化 AI 工作负载张量计算流水线。

## 2️⃣ AI 编译器与框架
- [编译器优化启发式的形式化保证](https://arxiv.org/abs/2608.20137):针对 NP-hard 编译优化问题中启发式搜索导致"烂码/长编译时间"的现象,提出验证编译器 pass 性能与编译时间性质的方法,把启发式缺陷当作可证明的 bug 对待。
- [DSLHyPE](https://arxiv.org/abs/2608.19273):面向 ExaHyPE 超算双曲 PDE 引擎的双语 DSL kernel 语言——物理项用 C/C++ 表达、数值格式用 Python 内嵌 DSL 描述,编译器将 Python 描述 lowering 到 MLIR。
- [Axon DSL](https://arxiv.org/abs/2608.19889):形状安全、框架无关的 LLM 架构 DSL,主打"一次编写、处处运行",缓解开源 LLM 生态对单一平台的依赖,降低模型定义在训练与推理框架间的迁移成本。

## 3️⃣ AI 推理优化(数据中心)
- [DiffusionGemma 技术报告](https://arxiv.org/abs/2608.00146)(HN 158 分):扩散式语言模型报告,为 LLM 并行解码(非自回归)与推理吞吐路线再添实证。
- [CacheRoute](https://arxiv.org/abs/2608.19677):大规模 LLM 服务的 prefix 亲和路由——用周期性路由计划把高命中率 key 纳入稳定热集并按预期负载分配,热 key 可部署多副本,化解"缓存盲分发 vs 固定亲和过载"的两难。
- [FleetSieve](https://arxiv.org/abs/2608.19659):面向 SLO 的 LLM 服务舰队配置 profiling,只测对最终资源分配有实际影响的 TP 度/副本数组合,避免穷举测量,适配负载动态变化。

## 4️⃣ 数据中心与基础设施
- [在 Apple Silicon 上重建 Linux MicroVM 栈](https://encore.dev/blog/firecracker-apple-silicon)(HN 143 分):Encore 分享在 Apple Silicon 上重建 Firecracker 类 microVM 栈的工程实践与权衡。
- [The Lazy Pod That Lies](https://arxiv.org/abs/2608.19412):评估 Kubernetes 上模型服务懒加载容器镜像(eStargz/SOCI vs 急切加载)的延迟成本与失效语义,工件覆盖 2~140GB 真实 fp16 模型。
- [Fast BFT SMR 最优性与权衡](https://arxiv.org/abs/2608.19629):快速拜占庭容错状态机复制的扩展版最优性分析,关注低冲突执行延迟、吞吐与公平性。
- [面向对地观测的本地化数据中心架构](https://arxiv.org/abs/2608.20283):为跨大西洋机构设计网络中心型本地(on-premises)EO 数据访问架构,应对连通性、主权与经费约束。

## 5️⃣ AI 安全与治理
- [Mechanistic Tomography](https://arxiv.org/abs/2608.19338):把 patching、梯度、Hessian 向量积、子集干预等统一为"机械化测量"框架,为控制导向的可解释性提供设计化测量范式。
- [黑盒 LLM 置信度估计改进](https://arxiv.org/abs/2608.19323):针对零样本、无标注数据的 LLM 不确定度量化(UQ),改进黑盒场景下的置信度评分性能。
- [神经网络证明共享的局限](https://arxiv.org/abs/2608.19351):揭示跨查询复用中间层抽象状态/模板加速不完备验证,在不同网络结构下存在鲁棒性边界。
- 近两天无重大政策/出口管制独立动态(背景:本窗口 JSON 无政策法规类条目)。

## 6️⃣ 具身智能
- [自演示生成式控制微调 VLA](https://arxiv.org/abs/2608.19490):用自演示生成式控制微调 π0.5 类 VLA,缓解新机器人硬件配置与预训练不匹配导致的性能骤降。
- [The Missing Touch](https://arxiv.org/abs/2608.19372):分布式触觉反馈让遥操作逼近人手灵巧度,实证提升遥操作数据采集质量。
- [SCAPE](https://arxiv.org/abs/2608.19425):场景条件、仿真增强的策略评估,用有限真实 rollout + 丰富仿真代理缓解 sim-to-real 偏差。
- [LLM 智能体何时有用:自动驾驶边缘调度](https://arxiv.org/abs/2608.19557):研究 LLM 作为自适应可解释调度器在异构 MEC 上处理混合关键级任务的截止期表现,给出"何时有效"的证据。
- [LF-GICP](https://arxiv.org/abs/2608.19522):无参数、退化感知的 LiDAR 里程计,用体素法向可定位性场识别不可观测轴,解决隧道/走廊退化漂移。
- [APPROVE](https://arxiv.org/abs/2608.19281):可视化终端用户在环的 LLM 机器人编程,增强透明度与用户意图对齐。
