## 3️⃣ AI 推理优化(数据中心)

- **🔥 GPT-6.2 Astra 与 Sol 发布,成本降到不足三分之一**:Astra 面向复杂专业工作(编程、computer use、ChatGPT Work / Codex / API),Sol 为日常模型;官方称在更强专业输出的同时大幅降本。对 infra 的含义是:同等预算下 agentic 多轮调用的可行域被再次放大(HN 1026 分)。[来源](https://openai.com/index/introducing-gpt-6-2-astra-sol/)
- **MLPerf Endpoints 首次提交,agentic 推理能效 10x**:英伟达在新增的 Endpoints 赛道以 Vera Rubin 拿下 10 倍以上优势,并把评测重心从单次训练吞吐转向「端到端 agent 交互」——这是基准体系第一次正式承认推理负载是长会话而非单请求。[来源](https://blogs.nvidia.com/blog/mlperf-training-endpoints-vera-rubin/)
- **SlipStream:给 GPU 推理降 HBF 延迟与 SRAM 开销**(佐治亚理工 + NVIDIA Research + 斯坦福):LLM 推理的容量瓶颈正从 HBM 外溢到 High-Bandwidth Flash,该工作通过缓解延迟与片上 SRAM 占用,使 HBF 能真正进入 GPU 内存层级而不拖垮解码速度。[来源](https://semiengineering.com/reducing-high-bandwidth-flash-latency-in-gpu-systems-georgia-tech-nvidia-stanford/)
- **多智能体场景的推理调度与缓存优化**(AICon 北京议题):把 KV cache 复用、请求路由与多 agent 并发放在同一调度层考虑,而非各自优化——这是当前 vLLM/SGLang 之外最容易被忽视的层间缝隙。[来源](https://www.infoq.cn/article/X8xujm6xovp7z2YzWbpM)
- **Microsoft-Decision-1.1 上线**:决策专用模型在 Microsoft Foundry、OpenRouter、Vercel 同步可用,官方称跑赢 GPT-6 Luna 与 Gemini;「小专用模型 + 通用大模型路由」的推理成本结构继续分化。[来源](https://www.ithome.com/1/028/593.htm)
