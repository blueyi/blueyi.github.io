## 2️⃣ AI 编译器与框架

- [What happens when you run a CUDA kernel?](https://fergusfinn.com/blog/what-happens-when-you-run-a-gpu-kernel/)(HN 197 分):一篇深度博客,从用户态 `cuLaunchKernel` 一路追到 GPU 上的 SM 调度与 warp 发射,几乎涵盖 CUDA Driver/Runtime、PTX→SASS、stream/context 全链路。是当下理解 Triton/torch.compile/MLIR-CUDA 后端必备的底层教材。
- [Same Coeffect, Different Base:连接 Graded Types 的两大主流方法](https://arxiv.org/abs/2606.28042):面向 Haskell/Idris/Granule 等的资源感知类型系统统一理论,长期看与编译器侧的副作用追踪、张量布局推断有交集。
- [Prophecy-Based Automated Verification of Message-Passing Programs](https://arxiv.org/abs/2606.28066):受 RustHorn 启发,把消息通道编码为"未来值列表"并约简为 CHC 求解,可直接用于验证 actor/通道式并发框架(对 JAX pjit、Triton-distributed、Ray 等的语义验证有借鉴价值)。
- [量子仪器单子(Quantum Instrument Monad)](https://arxiv.org/abs/2606.27805):把"计算与量子系统交互"的副作用建模为单子,延续 state monad 思路,适合 QPL/Quipper 风格语言后端建模。
- [纯 λ 演算中的循环图与记忆化](https://arxiv.org/abs/2606.22908):无需 letrec/μ/Y,用 tabling 同时支持循环数据与 memoization,有潜力影响纯函数式 IR 的图重写优化。
- 背景:今天 HN 上没有 tinygrad/MLIR/Triton 的独立大新闻,本节以底层 GPU 执行原理 + 类型系统/形式化语义论文为主。

## 3️⃣ AI 推理优化(数据中心)

- [DiStash:分布式多 stash 事务性 KV 存储](https://arxiv.org/abs/2606.27979):统一管理 DRAM/SSD/HDD/NVM 多级存储池的事务 KV,直接对应当下 LLM 推理中 KV Cache 跨 DRAM/NVMe/远端的分级管理需求,是 vLLM PagedAttention 之后向"分布式 KV 解耦"演进的论文级范本。
- [优化教师-学生切分以实现 HPC 上可扩展的知识蒸馏](https://arxiv.org/abs/2606.27797):指出 TRL 对师生模型对称处理是浪费——基于显存占用与通信差异做非对称切分,适用于大规模 7B→1B/3B 蒸馏管线的成本压缩,是面向数据中心训练/推理协同的工程优化。
- [Prism Transformer:层级注意力的渐进式 Head 调度](https://arxiv.org/abs/2606.27449):打破多头注意力"每层均分 d_h"的固有约定,按层级分配子空间维度,潜在收益是同等参数量下更高有效表达力 → 推理时可降低 head 数或层宽,直接影响 H100/B200 上的 KV/Attention 计算成本。
- [Mediators 的诅咒:Activation Patching 中的隐藏交互效应](https://arxiv.org/abs/2606.27510):机械可解释性方法学修正,与第 5 类相关;对推理优化的意义在于"基于电路理解做精准剪枝/量化"的可信度需要重新审视。
- 背景:本期 vLLM/SGLang/TensorRT-LLM 无独立大新闻,DiStash + 蒸馏切分代表了数据中心推理优化向"KV 存储分层 + 训练蒸馏一体化"的方向。

## 4️⃣ 数据中心与基础设施

- [FoggyTrust:基于层级信任网络的鲁棒联邦学习](https://arxiv.org/abs/2606.27622):FLTrust 的层级扩展,使大规模跨数据中心联邦训练在面对 Byzantine 客户端时更稳健。

- [探索与利用时间触发网络无关守卫的同步极限](https://arxiv.org/abs/2606.27819):时间触发协议中的网络守卫机制研究,关乎确定性低延迟网络(车载/工控),长期与 AI 数据中心的确定性网络化(SmartNIC/DPU)有交集。
- 背景:HN 今天无独立的液冷/网络/电力大新闻,本节以 HPC + 可信基础设施论文为主。

## 5️⃣ AI 安全与治理

- [PairSAE:基于 Pair 表征的蛋白质共折叠机械可解释性](https://arxiv.org/abs/2606.27440):把 SAE 从 transformer 序列嵌入推广到 pairformer 架构,扩大了可解释性方法的覆盖范围。
- [自动化可重复对手威胁仿真与效应语言 EL](https://arxiv.org/abs/2510.06420):用基于图的可视化编程语言 EL 自动化模拟 APT 多步攻击链,服务于防御侧训练与工具评测,是 AI + 网络安全红队自动化方向的实操工作。
- [自验证度量记录(再次相关)](https://arxiv.org/abs/2606.27934):从治理角度看,为"性能/能效报告"提供可审计证据图,有望成为未来 AI Hub/MLPerf 类基准的合规标配。
- 背景:今天无 EU AI Act / 美国出口管制 / 各国法案级别的独立新闻,本节以可解释性方法学修正 + 内容平台政策为主。

- [P-ARC 与 AO-ARC:并行 + 渐近最优多机器人运动规划](https://arxiv.org/abs/2606.27625) / [AO-ARC](https://arxiv.org/abs/2606.27495):分别在并行化与 anytime 最优性上扩展 ARC 框架,对仓储/无人车队的实时调度有直接价值。
- [学会投掷:四旋翼悬挂载荷的敏捷精准投放](https://arxiv.org/abs/2606.27603):面向急救/搜救场景的"动态释放"控制,补足传统 quadrotor 载荷传输的缺口。

## 7️⃣ AI 自动算子与代码生成优化

- 🔥 [HORIZON:把硬件设计视为仓库级代码演化的自演化 Agent 框架](https://arxiv.org/abs/2606.28279):用 Markdown harness 编译出包含领域知识、可执行评估器、验收谓词与 git 策略的 project pack,Agent 在隔离 worktree 中持续演化设计,几乎是把 AlphaEvolve / FunSearch 思路套到 RTL 仓库级,是本期最具方法论增量的工作。
- [MultModLM:面向 RTL 的多模态 LLM 硬件原理图生成基准](https://arxiv.org/abs/2606.27666):填补"LLM + RTL"研究偏文本生成的空白,提供 schematic 生成基准,直接为 ChipNeMo / Verigen 等多模态升级提供 evaluation harness。
- [PDAGENT-BENCH:面向 VLSI 物理设计的 LLM/VLM Agent 基准](https://arxiv.org/abs/2606.17253):从前端转向后端 PD(布局、布线、约束),给出标准化多阶段优化基准,是"芯片设计 Agent"走向 PnR 的关键基础设施。
- [AI 驱动的高科技系统设计综合(AiD / CDS)](https://arxiv.org/abs/2606.28126):用深度学习与生成式 AI 自动化系统级设计综合,以电驱与空间布局两个案例做 PoC,关联到自动算子/自动架构搜索这一更广泛的范式。
- [可解释 + 可验证测量记录(再次相关)](https://arxiv.org/abs/2606.27934):为 LLM 生成的 RTL/物理设计提供"基准结果可信"的基础设施,是 Agentic 硬件设计走向工业可用的关键一环。
- 背景:本期没有 AlphaEvolve / Triton kernel agent 类独立大新闻,HORIZON + 两个基准的组合,代表"LLM 写硬件"正从模型秀进入工程框架与评测期。
