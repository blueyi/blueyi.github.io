## 1️⃣ AI 芯片

- 🔥 [BitFair:12nm Bit-Serial CNN 加速器,面向超低功耗 XR 视觉](https://arxiv.org/abs/2607.05445) — 针对 XR 可穿戴的"始终在线"感知,在几瓦功耗、<20ms motion-to-photon 预算下,只留几毫秒给神经网络推理。BitFair 引入**可学习早停 (Learnable Early Termination)** 与**自适应位序 (Adaptive Bit Ordering)**,避免 ReLU 输出为 0 时仍处理全部位宽的浪费,是 bit-serial 架构做端侧视觉的一次工艺级(12nm 流片)落地。
- [Neuromorphic Silicon Neuron 控制器:面向帕金森自适应 DBS 的模拟脑神经元电路](https://arxiv.org/abs/2607.05453) — 大部分 aDBS 方案停留在算法/软件层,该工作把神经元动力学下沉到硅上,是"神经形态芯片进医疗器械"少见的电路级实现。
- [Bit2Watt:GPU workload 攻击数据中心电网的新型 CPS 漏洞](https://arxiv.org/abs/2607.05993) — 通过精心构造 GPU 工作负载,诱发**高频功率调制**,进而扰动上游电力电子/新能源接入。对于 100kW+ 机架和自建光伏/储能的 AI 数据中心,这是首次把"计算侧攻击"和"电网稳定性"直接串起来的漏洞披露。
- [FPGA:BRAM→DSP 直连路径提升 DL 算力密度](https://arxiv.org/abs/2607.05756) — 绕开全局布线网络的 BRAM-DSP 短路径,针对 DL 工作负载缩短关键路径,是 FPGA 架构演进对抗 NPU/GPU 的最新尝试。
- [GPU 加速的 3D IC 电源分配网络 (PDN) 有效电阻分析](https://arxiv.org/abs/2607.05818) — 面向 3D 堆叠的 TSV 规划,用 GPU 把 EDA 里的 effective resistance 求解并行化,是 3D IC 走向 chiplet+HBM 时代必要的工具链。

## 2️⃣ AI 编译器与框架

- 🔥 [InvWeaver:面向多循环交互程序的 LLM+演绎反馈循环不变量合成](https://arxiv.org/abs/2607.05478) — 传统 LLM guess-and-check 方案在多循环耦合时失效,InvWeaver 用**神经-符号闭环**把演绎证明失败信息回喂给 LLM。对 XLA/TVM/MLIR 里做仿射循环优化和验证的方向有直接借鉴意义。
- [Compiling Bioinformatics Recurrences](https://arxiv.org/abs/2607.06225) — DP 矩阵递推的**执行顺序重排 + 无效区域剪枝**编译化,是把 Halide 式 schedule/algorithm 分离思路推向生信 DP 内核的一次系统工作,长远看和 Triton/Mojo 追求的"科学计算 DSL"路线共振。
- [Flow Sensitivity without CFG:高效 Andersen 风格流敏感指针分析](https://arxiv.org/abs/2508.01974) — 甩掉控制流图仍保留流敏感,大幅降低编译期指针分析开销;对 LLVM/MLIR 里做全程序优化的 pass 是量级级的性能提升。
- [PatchOptic:面向共享状态 LLM 工作流的投影视图与可验证结构化更新](https://arxiv.org/abs/2607.05483) — 不是传统编译器,但把"agentic 工作流的上下文管理"当成一种**编译问题**处理——每一步只给 LLM 看结构化状态的一个视图,更新时做类型校验。对 vLLM/SGLang 之上的 agent runtime 有工程价值。
- [CANONIC:把"治理"变成"编译"](https://arxiv.org/abs/2607.05410) — 用编译器/文法的思路机械化判定 LLM 生成内容能否进入语料库,是给"AI slop 危机"提出的一个结构化解法,兼跨 2/5 类。

## 3️⃣ AI 推理优化(数据中心)

- 🔥 [UBEP:面向生产超节点重构专家并行通信库](https://arxiv.org/abs/2607.06202) — 直击 NVL72/576、华为 CloudMatrix384 上 MoE 部署的三大瓶颈:栈式通信、全局地址空间调度低效、稀疏路由。作者重新架构 EP 通信库并把优化专门做在**全带宽 fabric 拓扑**上,是数据中心 MoE 推理今年最重要的 systems 工作之一。
- [MatrixFSDP:ZeRO-3 分片下无通信矩阵优化器](https://arxiv.org/abs/2607.05895) — Muon 这类矩阵型优化器需要完整 2D 矩阵做 Newton-Schulz 正交化,天然和 FSDP/ZeRO-3 的分片语义冲突。作者给出免通信版本,是"下一代优化器 × 大规模分布式训练"必须过的一关。
- [Design-CP:面向蛋白质纳米颗粒设计的 Context Parallelism](https://arxiv.org/abs/2607.05439) — 把 CP 思路推广到 RFdiffusion 3,做 1D 行分片和 2D 网格分片,让蛋白质多链复合体设计突破单 GPU 显存墙。生物场景验证 CP 已经从 LLM 长上下文外溢到通用 all-atom 生成模型。
