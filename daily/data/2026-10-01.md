## 3️⃣ AI 推理优化(数据中心)

- [SPLASH:注意力并行布局的无缝交接切换](https://arxiv.org/abs/2609.37626) — 低并发适合 TP、多独立请求适合 DP-attention、长 prompt 适合 CP;reasoning/agentic/RL-rollout 下"一个 batch 从头到尾形态在变",固定布局不可维持。
- [DScale:块扩散投机解码的自适应验证](https://arxiv.org/abs/2609.37532) — 高并发下块扩散 SD 的三大损耗是验证 padding、候选被拒、变长前缀与固定形状图不兼容,统一截断会白扔可接受 token。

- [Efficient Agentic LLM Serving over SSD-based Sparse KV Storage](https://arxiv.org/abs/2609.36938) — Agentic 会话在"推理—工具调用"间反复累积历史,稀疏注意力 + SSD 落盘 KV 是当前最务实的显存换带宽方案。

- [Purlin:把集合通信的编排与数据面拆开](https://arxiv.org/abs/2609.36954) — 语义/编排/数据面解耦,新硬件机制与新 workload 定制不必再重写整条通信栈。
- 成本面:[GPT-6.1 Sol 以"Astra 五分之一"的输入输出价格主打编码与 computer use](https://openai.com/index/introducing-gpt-6-1-sol/),叠加 [CoreWeave 与 NVIDIA 用 Vera Rubin 打通 agentic AI 训练到生产的闭环](https://blogs.nvidia.com/blog/coreweave-agentic-ai-vera-rubin/),单位 token 成本的下降通道仍在继续。

## 🌟 今日亮点

1. **一句话概括今天**:模型在压价(GPT-6.1 Sol 以 Astra 五分之一的价格打 coding 与 computer use),芯片厂在买模型能力(AMD 82 亿美元吞 World Labs),而软件栈在"跨芯片"(DeepSeek 把 TileLang/DeepGEMM/DeepEP/FlashMLA 全套铺到昇腾 950)——三条线都在回答同一个问题:算力成本什么时候、以什么方式被摊薄。
2. **推理侧的技术共识正在形成**:SPLASH、DScale、vSkipper 三篇独立工作指向同一个失效点——固定并行布局与静态形状假设,在 agentic / reasoning / RL-rollout 这类"batch 形态中途变化"的负载下不再成立。做 serving 的人应当把"运行时重排 + 自适应验证 + 跳层真能降延迟"当成一组联立问题,而不是三个独立开关。
3. **Agent 的常驻化改变基础设施假设**:OpenAI dots 这类 always-on 个人 Agent([据 Geekbench 7 跑在 9 核 AMD EPYC 云 VM、约 10GB 内存上](https://www.tomshardware.com/tech-industry/artificial-intelligence/geekbench-7-results-suggest-openais-dots-agent-runs-on-nine-core-amd-epyc-vms-with-nearly-10gb-of-memory-newest-runs-score-about-six-times-meta-muse-in-multi-core)),把"对话式推理"换成"长期驻留工作负载",直接推高常驻算力、KV 存储与 SSD 卸载的需求(呼应 3️⃣ 的 SSD sparse KV 工作)。
4. **治理从"原则"落到"谁能用、用来做什么"**:白宫自愿性安全协议、Gemini 4 Argon 按可信防御者定向发放、FTC 立案调查、以及 OpenAI 对蒸馏行动的技术阻断 + 月之暗面的中文侧争议,四条线合起来说明前沿模型的合规成本正在从"发布前评测"转移到"使用中的可追溯性"。
5. **一句待观察**:中文媒体称 OpenAI 在 DevDay 前夜收回了 GPT-6.1 Astra 的发布计划([新智元](https://aiera.com.cn/2026/09/30/other/admin/116242/openai%e7%b4%a7%e6%80%a5%e5%8f%ab%e5%81%9cgpt-6-1%ef%bc%81/)),与官方已上线 Sol 版本的口径不一,发布节奏本身正成为安全叙事的一部分,值得跟踪。
