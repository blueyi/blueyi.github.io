## 2️⃣ AI 编译器与框架

- 🔥 [智源众智 FlagOS 2.2：让前沿模型与多元算力协同演进](https://www.infoq.cn/article/mhdJwMMzYFedMFHKfHWs) — 国内最成体系的"一套软件栈打通多种加速器"工程：训练/推理算子库、通信库、跨芯片编译与调优层统一抽象，目标是让模型不必为每家国产芯片重写一遍。相比单点适配，这类栈的价值在于把 N 种芯片 × M 个模型的组合成本压成 N+M，是国产算力生态能否规模化的关键变量。

- [NVIDIA Kumo Relational：关系数据上无需训练即超越监督学习](https://huggingface.co/blog/nvidia/kumo-relational) — 把"学习"从训练阶段挪到查询阶段，对框架层的含义是：数据栈与推理运行时开始融合，未来 pipeline 里"训练 / 推理 / 查询"的边界会进一步模糊（推理视角见 3️⃣）。

## 3️⃣ AI 推理优化（数据中心）

- 🔥 [Kimi K3.1 泄露：3D 资产成本仅 GPT-6 Astra 的 1/14](https://www.leiphone.com/category/yanxishe/PZo9w14YeFSo4jmf.html) — 官方先导片被扒出彩蛋，主打"15 分钟交付工业级可交互 3D 资产"。真正的信息点是单位生成成本差了一个数量级——多模态生成的竞争已经从"能不能做"转到"每个 token / 每帧多少钱"，这是推理侧调度、缓存复用与模型结构共同决定的系统级指标。
- [Gemma-4-26B-A4B：同等准确率下减少 39%–69% 的思考量](https://bottlecapai.com/post/thinkingcap-gemma-4-26b/)（HN 123）— 用 26B 总参 / ~4B 激活的 MoE 结构配合"thinking cap"控制，把推理期思维链长度当作可调预算来压。对线上服务而言，这意味着同一精度下 decode 阶段的 token 数直接砍半，是当前最划算的一类"零成本加速"（端侧视角见 8️⃣）。
- [NVIDIA Kumo Relational：关系数据上零训练超越监督学习](https://huggingface.co/blog/nvidia/kumo-relational) — 若成立，可把大量表格类预测任务从"训练 + 特征工程 + 部署"压缩成一次查询期推理，省掉的是整条训练流水线的算力与运维，而不是单次前向的 FLOPs。
- [「让 Token 不空转」：讯飞如何把 Agent 推进企业核心流程](https://www.infoq.cn/article/Lo9TLlRdvy4II38yaex0) — 企业侧的真实瓶颈不是峰值吞吐而是"无效 token"：重复检索、无效工具调用、上下文反复重述。文中把 token 预算按业务步骤分配、把长上下文做成可复用的中间态，属于典型的 Agent 时代推理成本工程，和传统 batching/量化是互补而非替代。
