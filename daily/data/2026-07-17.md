# 📡 AI Infra 日报 · 2026-07-17(周五)

> 覆盖窗口:2026-07-15 ~ 2026-07-17 · 信息源:Hacker News / arXiv

## 1️⃣ AI 芯片

- [The Economics of AI Decoding Chips: Rebalancing Compute, Capacity, and Bandwidth for Efficient LLM Inference](https://arxiv.org/abs/2607.13068) — 一篇直击当下痛点的经济学 + 架构分析:主流 GPU 都是"算力重、容量轻",而 LLM decoding 恰好需要"算力轻、容量重",FP 单元利用率只有个位数百分比,内存却被强制和昂贵的 HBM 捆绑销售。作者呼吁重新平衡 compute / capacity / bandwidth 三者比例,为 decoding 专用芯片(而非通用 GPU)提供了明确的经济学论证。
- [CIMERA: Compute-in-Interconnect and Memory with Reconfigurable Precision for LLM Inference](https://arxiv.org/abs/2607.13649) — 存算一体 + 互连内计算(CIM + CII)的 LLM 推理架构,支持可重构精度以适应 LLM workload 的异构性和精度容忍度差异,面向从数据中心到边缘的能效比优化。
- [Kaleido: Algorithm-Hardware Co-Design for Video Diffusion Transformers by Exploiting Latent Space Correlations](https://arxiv.org/abs/2607.13770) — 视频扩散 Transformer 的算法-硬件协同设计。稀疏注意力的既有 LLM 套路对 vDiT 失效,Kaleido 通过挖掘 latent 空间相关性来降低 self-attention 主导的计算瓶颈。
- [Microflow: Microarchitectural Causal Observability for Deep Cross-Layer Analysis and Optimization](https://arxiv.org/abs/2607.13184) — 架构模拟器新范式:不再只给聚合指标或原始 trace,而是揭示微架构事件之间的因果关系,让架构师能跨抽象层追溯性能症状的根因。

## 2️⃣ AI 编译器与框架

- [Generative Compilation: On-the-Fly Compiler Feedback as AI Generates Code](https://arxiv.org/abs/2607.13921) — 把编译器反馈直接嵌进 LLM 自回归解码过程。Rust 这类强静态语义语言对 AI 生成代码更友好,但也更难生成;传统方案是 post-generation 反馈,constrained decoding 又太粗。本文让编译器与生成过程实时对话,拒绝在中间步骤产生的非法路径。对 AI Coding + 编译器社区都是关键一步。
- [Executable JavaScript as a Checkable Specification Language: A JS-SAM Case Study on SysMoBench](https://arxiv.org/abs/2607.13092) — 讨论 LLM 用主流语言(JS)vs 稀有形式语言写规范的忠实度差异,通过真实系统执行 trace 回放来打分。对 spec-driven code generation 与形式化验证的融合方向有借鉴价值。
- [Decomposable Type Highlighting for Bidirectional Type and Cast System](https://arxiv.org/abs/2607.13727) — 面向静态/动态类型错误调试的可分解类型高亮系统的数学基础,对 gradual typing 编译器友好度是长期基础工作。

## 3️⃣ AI 推理优化(数据中心)

- 🔥 [Full-Pipeline Inference Optimization for MiMo-V2.5 Series: Pushing Hybrid SWA Efficiency to the Limit](https://arxiv.org/abs/2607.13095) — 小米 MiMo-V2.5 系列的全流水线推理优化。Hybrid Sliding Window Attention + 稀疏 MoE + 多模态编码器三件套,理论上 SWA 相比 Full Attention 可以大幅降低 attention 计算和 KV Cache,但工程落地需要大量投入。这篇给出了 SWA 家族在生产环境榨干效率的完整实战路径,是继 Mistral / Character.AI 之后又一份重要的 SWA 部署报告。
- [Uncertainty-Aware Sequential Decision Rules for Event-Triggered LLM Invocation in Streaming Systems](https://arxiv.org/abs/2607.13048) — 流式推理管线里的"何时触发 LLM"问题被形式化为风险驱动的序贯停止问题:轻量快模型 + LLM 组合,通过风险泛函决定何时才付昂贵的 LLM 调用成本。对成本敏感的在线推理系统是可直接落地的策略层优化。
- [Beyond Backbone Backpropagation: A Decoupled Strategy for Efficient Transfer Learning](https://arxiv.org/abs/2607.13043) — 通过只适配 normalization 层、特征只算一次、重设计分类头等手段大幅降低训练/微调开销,为推理侧的持续更新场景提供了低成本重训方案。

## 4️⃣ 数据中心与基础设施

- 🔥 [Making 768 servers look like 1 (PlanetScale)](https://planetscale.com/blog/making-768-servers-look-like-1) — HN 144 分。PlanetScale 揭示如何把 768 台服务器抽象成"一台数据库",Vitess 分片 + 元数据平面的工程实践对训练/推理集群的编排也有借鉴意义。
- 🔥 [Let's Build PlanetScale from Scratch: Infrastructure](https://onatm.dev/2026/07/16/homescale-part-1/) — HN 130 分。从零复刻 PlanetScale 基础设施的系列首篇,覆盖多可用区、副本、路由层的 hands-on 搭建,是理解现代分布式数据库栈的一份高质量教程。
- 🔥 [Agora: Collective and Permissionless Internet-Scale Pretraining of Large Language Models](https://arxiv.org/abs/2607.13332) — 打破数据中心内 DP/MP 的同构 GPU + 高速互连 + 单一编排者假设,提出面向异构算力、开放接入、互联网规模的 LLM 预训练框架。若可行,将极大改变谁能训 frontier model 的格局。
- [The Environmental Cost of Digital Sovereignty: Water, Energy, and Emissions Impacts of Sovereign AI Infrastructure in the Global South](https://arxiv.org/abs/2607.13443) — 2024-2026 全球南方国家已宣布 2000 亿美元以上的主权 AI 承诺,本文量化其数据中心带来的水、能、碳成本,是理解主权 AI 浪潮真实约束的一份必读评估。
- [gDMC: A Generic Distributed Model Counting Framework via Work-Stealing](https://arxiv.org/abs/2607.13634) — 分布式精确 #SAT 框架,C++ 模板解耦并行策略,work-stealing 缓解静态分解的高初始化开销,是分布式系统层可复用的一份工程模板。
- [A Distributed Framework for Compiling and Reasoning with d-DNNF](https://arxiv.org/abs/2607.13642) — 面向知识编译离线阶段成为主要瓶颈的问题,给出分布式 d-DNNF 编译框架。

## 5️⃣ AI 安全与治理

- 🔥 [The privacy problems hidden in your period tracker (BBC)](https://www.bbc.com/future/article/20260715-how-period-trackers-share-womens-private-details) — HN 61 分。经期追踪 App 悄悄共享女性隐私数据,再次把消费级 AI/健康 App 的数据治理推上台面,和最近多国推行的数据本地化 / 敏感数据出口管制形成呼应。
- [Fair on the Surface: Transaction-Ordering Bias and MEV in Mysticeti DAG-based BFT Protocol](https://arxiv.org/abs/2607.13378) — SOTA DAG-BFT 共识协议 Mysticeti 中的交易排序偏差与 MEV 攻击面分析。放在 AI 治理里的意义:任何"看似公平"的排序/调度机制,都可能在实际部署时被博弈,AI 推理调度器亦然。
- [What Your Model Threw Away and Why You'll Want It Back: Masking, Fingerprinting, and Privacy from Discarded Geometry](https://arxiv.org/abs/2607.13046) — 用 Lie 群作用的几何视角,量化"模型丢弃了什么信息",给出用于遮蔽、指纹、隐私分析的统一框架,是可解释性 + 隐私交叉方向的新工具。
- [Targeted Recovery of Weight-Space Mechanisms From Neural Networks](https://arxiv.org/abs/2607.13047) — Parameter Decomposition (PD) 扩展到大模型代价高昂,tPD 只针对特定输入相关的组件做分解,把可解释性研究的算力门槛拉低一个量级。
- [Federated Explainable Artificial Intelligence: Roles, Architectures, Evaluation, and Open Challenges](https://arxiv.org/abs/2607.13045) — 联邦学习 + XAI 的系统性综述,直击"数据不出域但模型仍不透明"的合规痛点。

## 6️⃣ 具身智能

- 🔥 [Worlds in One Demo: A Synthetic Data Engine for Learning Open-World Mobile Manipulation](https://arxiv.org/abs/2607.13154) — 开放世界移动操作策略学习需要海量数据,teleoperation / UMI 成本过高。本文提出"一次演示、生成多世界"的合成数据引擎,把每一次人类演示的价值榨到最大,直指当前 VLA 数据卡脖子问题。
- [HRIBench: Benchmarking Interaction-Centric Human-Robot Collaboration](https://arxiv.org/abs/2607.13056) — 现有 VLA benchmark 只测孤立操作,本 benchmark 强调共享自主性下的意图理解、时间同步、协议遵循与安全交互,是人机协作走向真实工厂/家庭场景的关键评测集。
- [GPUSimBench: Towards Scalable and Reliable GPU-Accelerated Simulators in Embodied AI](https://arxiv.org/abs/2607.13059) — 直面 GPU 加速仿真器在并行效率、物理保真度、执行确定性之间被忽视的权衡,提供系统 benchmark。对所有做 Sim2Real 的团队都是选型必读。
- [A 3DGS-Driven Dynamic Viewpoint and Vibrotactile Framework for Subsea Teleoperation Validated via fNIRS](https://arxiv.org/abs/2607.13067) — 3D Gaussian Splatting 驱动的动态视角 + 振动触觉 subsea 遥操作框架,ROS-Unity 架构 + fNIRS 神经生理学验证,是 3DGS 在遥操作场景的一次扎实工程落地。
- [A Bayesian framework for the uncanny valley in humanoid robot design](https://arxiv.org/abs/2607.13060) — 首次把"恐怖谷"从经验规则变成可操作、可量化的贝叶斯设计变量,人形机器人外观设计从此可以做梯度下降。
- [HRO: Hierarchical Room-to-Object Framework for Zero-Shot Object Goal Navigation with LLMs](https://arxiv.org/abs/2607.13072) — LLM 先验驱动的零样本物体目标导航,分层 room-to-object 结构提升未知场景中的探索效率。
- [Autonomous UAV Route Planning for Coverage Maximization in Environmental Monitoring: A Systematic Literature Review](https://arxiv.org/abs/2607.13054) — 覆盖导向 UAV 路径规划的系统性综述,SLR 协议 + 初步结果。
- [Power from Potential: A Survey of Electrostatic Actuators for Haptics](https://arxiv.org/abs/2607.13058) — 高压静电执行器 (HVEA) 综述,面向可穿戴场景要求的软、薄、静音、低功耗触觉反馈。

## 7️⃣ AI 自动算子与代码生成优化

- 🔥 [ChipVerilog: A Large-Scale OpenCores-Derived Benchmark for LLM-Based Verilog RTL Generation](https://arxiv.org/abs/2607.13079) — 现有 LLM Verilog benchmark 都是短小自包含的模块级任务,无法反映真实 IP / 处理器核 RTL 的规模、层级和模块间交互。ChipVerilog 从 OpenCores 派生,把 LLM 写 RTL 拉到工业级评测,是继 VerilogEval / RTLLM 之后又一里程碑,对芯片设计自动化社区意义重大。
- [Generative Compilation: On-the-Fly Compiler Feedback as AI Generates Code](https://arxiv.org/abs/2607.13921) — (与第 2 类交叉)让编译器在 LLM 解码时逐 token 反馈,不仅是编译器话题,更是"自动生成 + 自动纠错"最扎实的算子/代码生成新范式之一。
- [Theory-Level Autoformalization: From Isolated Statements to Unified Formal Knowledge Bases](https://arxiv.org/abs/2607.13292) — 立场论文:autoformalization 不应停留在孤立命题,应该整个理论级(公理 + 定义 + 引理)一起形式化。对 AI 数学助手 + 定理证明生成方向定调。
- [Elton: Urn Resources for Reasoning about Adversarial Probabilistic Programs](https://arxiv.org/abs/2607.13459) — 面向包含对抗性未知代码的高阶概率程序的高阶分离逻辑,是"生成的代码要在敌手存在下依然可证明安全"这条路上的基础工作。

## 8️⃣ 边缘与端侧推理

- [No Attention, No Problem: DPU-Aware Attention Approximation in Modern YOLO on FPGA](https://arxiv.org/abs/2607.13106) — 面向 AMD FPGA 的 DPU 感知架构,针对基于注意力的 YOLO 变体做近似,兼顾精度/速度/功耗。边缘目标检测部署侧一份非常实际的工程报告。
- [CIMERA: Compute-in-Interconnect and Memory with Reconfigurable Precision for LLM Inference](https://arxiv.org/abs/2607.13649) — (与第 1 类交叉)可重构精度 + 存算/互连一体,同样覆盖功耗受限的边缘设备,是端侧 LLM 芯片方向的一份 hardware-heavy 提案。
- [TSSM: Triaxial State Space Model for Global Station Weather Forecasting](https://arxiv.org/abs/2607.13101) — SSM 在低算力气象终端上做全局站点预报,展示了 SSM 家族在端侧长序列任务上的实用性。
- 背景:llama.cpp / MLC-LLM / MLX / ExecuTorch 近两天无公开重大版本或新硬件后端消息;端侧 LLM 讨论热点仍集中在上周宣布的高通/联发科新 NPU 与手机厂商 SDK 落地。
