## 1️⃣ AI 芯片
- 🔥 [AMD Ryzen AI Halo – $4k AI Dev Kit](https://www.lttlabs.com/articles/2026/07/06/amd-ryzen-ai-halo)(HN 371 分):AMD 推出面向本地 AI 开发的 Halo 套件,定价约 4000 美元,主打统一内存 + NPU 的一体化本地推理开发平台。这类"桌面级 AI 工作站"正成为绕开云端 GPU 排队的新品类,对小团队原型开发有吸引力。
- [FAPlace: Chiplet Placement 与 Interposer Footprint 联合优化](https://arxiv.org/abs/2607.02610):针对 2.5D 系统集成,破解"footprint 依赖 placement、placement 又受 footprint 约束"的循环依赖,联合优化硅中介层布局。HBM/多 die 封装时代的物理设计基础工作。
- [HyNoC:FPGA 上分布式 VLIW 计算的混合电路交换/虫洞 NoC](https://arxiv.org/abs/2607.02729):开源片上网络架构,结合电路交换建路与虫洞数据传输,平衡延迟、面积与拥塞。

## 2️⃣ AI 编译器与框架
- [Kotlin-MP:面向并行的 DSL 与 IR Transformer](https://arxiv.org/abs/2607.02519):Kotlin 有优秀的协程异步抽象,但缺低开销、指令式的硬件并行构造。该工作用编译器 IR 变换消除 lambda 分配与状态机开销,给计算密集循环加真并行。
- [Tile-Level Activation Overlap 高效 LLM 推理](https://arxiv.org/abs/2607.02521):SwiGLU 中间张量物化占 MLP 执行 9–37% 时间。基于 CUTLASS 的两个 SM90 kernel 把 SwiGLU 在 tile 级融进 GeMM(Pingpong warp 专用调度),典型的编译器/kernel 协同优化。
- [静态 PTX 指标能追踪结构性 kernel 回归,却漏掉语义性回归](https://arxiv.org/abs/2607.02541):在 3060/A10/L40S/A100/H100 五类 GPU 上把静态 PTX 指标与 CUDA event 实测配对,发现 Δregs/Δinstrs 跨 GPU 完全一致但无法捕捉语义 bug——对自动调优的可观测性有直接启示。

## 3️⃣ AI 推理优化(数据中心)
- [PEEK:队列感知的预测式 KV Cache 管理](https://arxiv.org/abs/2607.02525):在 pending 队列上维护增量 radix tree,暴露现有引擎看不到的 prefix-sharing 簇,通过双向遍历匹配引擎 prefix cache 做最长前缀匹配调度与驱逐,面向在线流式 LLM 服务。
- [GLM-5 面向 OpenClaw 的单部署 MaaS 推理调参](https://arxiv.org/abs/2607.02518):针对 28k–30k 输入 / 500 输出的长上下文、工具增强 Agent 负载,服务质量由吞吐、TTFT 与尾延迟主导,给出 serving 参数调优经验。Agent workload 越来越成为服务优化的独立场景。
- [Multi-Turn 分布式 MoE 推理(6G 边云)](https://arxiv.org/abs/2607.02522):揭示 MoE 边云推理中 KV 局部性与弹性专家分派之间的张力——KV 迁移开销大,是数据中心/边缘 MoE 调度的核心权衡。

## 4️⃣ 数据中心与基础设施
- [PostgreSQL 跨 23 种 EC2 实例类型的性能与成本](https://postgres.saneengineer.com)(HN 82 分):Show HN 实测,给出不同实例型号下 Postgres 的性价比曲线,对云端选型是实用参考。
- [SWIFT:小波集成的时空云负载预测框架](https://arxiv.org/abs/2607.02524):纯卷积框架,针对高波动、易突发的云工作负载,兼顾时间局部性与空间依赖,服务于资源调度。
- [Kubernetes 运维记忆架构:证据视界分类学](https://arxiv.org/abs/2607.02528):形式化 K8s 事件保留模型按确定性时间表丢弃最有诊断价值上下文的机制,提出"证据视界"五类边界,面向集群可观测性。

## 6️⃣ 具身智能
- [GigaWorld-1:构建机器人策略评估世界模型的路线图](https://arxiv.org/abs/2607.02642):机器人策略评估依赖缓慢昂贵的真机 rollout,推动用世界模型做代理评估器,系统梳理可靠 world model 的关键属性。
- [CLEAR:面向端到端自动驾驶的大规模闭环强化学习](https://arxiv.org/abs/2607.02841):将 VLA 范式引入 E2E-AD,统一视觉感知、语言理解与动作预测于单一策略,并做大规模闭环 RL。
- [DREAMSTEER:潜在世界模型无需微调即可在部署时引导 VLA 策略](https://arxiv.org/abs/2607.02865)与 [TACO:触觉世界模型作为 VLA 后训练自校正器](https://arxiv.org/abs/2607.02840):两篇都攻 VLA 在部署时分布漂移/接触密集任务的失败,前者免微调引导,后者用触觉做局部纠错。
- [MorphQuad:可变形四旋翼,追求超人机动/操作/韧性](https://arxiv.org/abs/2607.02764);[EVA-Client:真机策略数据采集/推理/部署统一框架](https://arxiv.org/abs/2607.02646)补充了硬件与工程侧进展。

## 7️⃣ AI 自动算子与代码生成优化
- [ArchEval:把 AI Agent 当计算架构师来测量](https://arxiv.org/abs/2607.03601):新基准,要求 agent 解读负载、选机制、用模拟器、预测性能、满足硬约束并决策——超越"写代码/调参"的能力度量,是 LLM 做架构探索的评测基础。
- [SABLE:NDA 安全的闭环 LLM 模拟电路优化框架](https://arxiv.org/abs/2607.03701):让 LLM 通过 Cadence Virtuoso 等工业 EDA 流优化模拟电路,同时不向云端暴露 PDK、专有原理图与许可绑定工具状态。工业级 LLM-driven EDA 的合规范式。
- [Attributing Structured-Output Gains in Function Calling](https://arxiv.org/abs/2607.02595):提出四层增益归因协议,区分函数调用中的接口对齐 vs 可迁移程序性技能——对"prompt 注入式 skill"的真实收益做严谨归因。

## 8️⃣ 边缘与端侧推理
- 🔥 [AMD Ryzen AI Halo 开发套件](https://www.lttlabs.com/articles/2026/07/06/amd-ryzen-ai-halo)(HN 371 分):除数据中心视角外,它本质是端侧/桌面本地推理平台,统一内存 + NPU 让本地跑较大模型成为可能(与第 1 类交叉,此处从端侧落地角度带过)。
- [边缘单 GPU 微调 LLM 用于电信网络排障](https://arxiv.org/abs/2607.02523):电信边缘站点受电力、散热、空间与重量预算约束,该工作在单 GPU 上完成本地微调,满足低延迟与数据主权要求,是端侧适配的务实案例。
- [面向可迁移轻量神经形态计算的无模型时序开关框架](https://arxiv.org/abs/2607.02608)与 [AIGOR:模块化事件驱动 SNN 推理架构](https://arxiv.org/abs/2607.03191):从神经形态/SNN 方向探索资源受限边缘部署,应对器件差异导致的重训练成本。
