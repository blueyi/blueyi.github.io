# 📡 AI Infra 日报 · 2026-08-08 (周六)

## 1️⃣ AI 芯片

- 🔥 **AMD 收购 Taalas，将模型直接蚀刻进硅片以提升推理性能** — [The Register](https://www.theregister.com/systems/2026/08/06/amd-acquires-ai-chip-startup-taalas-to-boost-inference-performance-by-etching-models-into-silicon/5284344) (HN 880)。Taalas 的技术路线是将 Transformer 模型直接"蚀刻"为专用硅电路，绕过传统指令集架构实现极低延迟推理。这是 AMD 在定制 AI 硅片赛道对 NVIDIA 和 Google TPU 的正面回应。
- [Can you reverse engineer an ASIC?](https://blog.janestreet.com/can-you-reverse-engineer-an-asic/) (HN 106) — Jane Street 从金融交易角度系统探讨逆向工程 ASIC 的可行性、成本与法律边界。
- **自动化异构分层缓存一致性协议合成** — [arXiv](https://arxiv.org/abs/2608.05965) 提出自动合成 CXL/AMBA CHI 等多级协议间的 shim 层，解决 CPU+GPU+NPU 异构集群的缓存一致性问题。
- **PowerScope: ML 驱动的亚时钟周期功耗估计** — [arXiv](https://arxiv.org/abs/2608.05339) 用 ML 在亚周期粒度估算芯片功耗，用于 PDN 设计与电压跌落分析。

## 2️⃣ AI 编译器与框架

- [Making Postgres 300x faster: batching, operator fusion, and SIMD](https://malisper.me/how-we-made-postgres-hundreds-of-times-faster-the-query-engine/) (HN 236) — 虽属数据库领域，但其算子融合 + SIMD 向量化思路与 MLIR/Triton 编译 pipeline 高度共鸣，对 AI 编译器开发者有直接参考价值。
- **RepoOMP: 仓库感知的 OpenMP 热点并行化** — [arXiv](https://arxiv.org/abs/2608.05855) 结合依赖分析的混合框架，在大型代码库中自动识别并安全并行化热点循环，克服纯规则工具的保守性和纯 Agent 方案的不稳定性。
- **Let it Flow: 形式化验证的异步数据流编译框架** — [arXiv](https://arxiv.org/abs/2608.05451) 面向空间数据流架构（如 Systolic Array），给出可验证的编译正确性保证。
- **PPDL: 将 LLM 工作流建模为概率程序** — [arXiv](https://arxiv.org/abs/2608.05234) 为多步 LLM 调用链提供形式化可靠性基础，对 LLM 驱动的编译优化流程有参考意义。

## 3️⃣ AI 推理优化(数据中心)

- [Inside vLLM: Anatomy of a High-Throughput LLM Inference System](https://www.aleksagordic.com/blog/vllm) (HN 142) — 系统剖析 vLLM 的 PagedAttention、Continuous Batching 与 GPU 内存管理等核心技术，理解 LLM 推理引擎设计的必读材料。
- **TensorCast: LLM 基础设施中缺失的张量管理层** — [arXiv](https://arxiv.org/abs/2608.06007) 指出模型加载、KV Cache、checkpoint 同步各自为政，提出统一的张量管理抽象层。
- **PLoRA: 基于近存计算(NDP)的多 LoRA 高效推理** — [arXiv](https://arxiv.org/abs/2608.05483) 将热门适配器置于近存计算单元避免 PCIe 往返延迟，显著降低千级 LoRA 多租户推理成本。

## 4️⃣ 数据中心与基础设施

- 🔥 **NVIDIA B300 双节点全量微调实战报告** — [arXiv](https://arxiv.org/abs/2608.05944) 首批公开发表的 B300 集群经验：16×B300 (FSDP/ZeRO-3) 全量微调 Qwen3-32B，含 telemetry 诊断与运维加固心得。
- **碳感知推理路由：LLM 请求实时调度到最清洁电网** — [arXiv](https://arxiv.org/abs/2608.06188) 在多区域 GPU 集群上验证基于边际碳排放率(MOER)的实时路由，碳排放可降一个数量级。
- **面向 Agentic Science 的分层服务器架构** — [arXiv](https://arxiv.org/abs/2608.05332) 跨机构动态分层架构，自动发现调度异构资源支撑 Agent 驱动科学计算。
- **eMicro: 基于 eBPF 的微服务多跳访问控制** — [arXiv](https://arxiv.org/abs/2608.05300) 解决微服务逐跳鉴权无法防御多跳攻击的痛点，实现全路径安全策略执行。

## 6️⃣ 具身智能

- **VLAff: 视觉-语言-可供性统一模型** — [arXiv](https://arxiv.org/abs/2608.05215) 从第一人称人类视频中学习物体中心的可供性(affordance)，实现跨 embodiment 的机器人操作技能迁移。
- **World-to-Wrist (W2-VLA): 任务条件化腕部未来建模** — [arXiv](https://arxiv.org/abs/2608.05369) 基于全局任务上下文预测腕部区域未来交互，显著提升 VLA 模型的精细操作能力。
- **ARGUS: 跨视角对齐机器人场景几何** — [arXiv](https://arxiv.org/abs/2608.05579) 用大型 3D 视觉模型对齐不同视角的场景几何，解决 VLA 策略将物体位置与特定视角纠缠的问题。
- **Failing Gracefully: 缓解机器人不可避免的故障影响** — [arXiv](https://arxiv.org/abs/2608.05313) 研究家用服务机器人在软件崩溃/硬件退化下的优雅降级策略。
- **PathCover: 基于随机迭代空间划分的快速凸分解** — [arXiv](https://arxiv.org/abs/2608.05586) 从点云实时生成无碰撞凸区域用于自主导航轨迹规划。

## 7️⃣ AI 自动算子与代码生成优化

- [Learning Context-Free Grammars for Grammar-Constrained Decoding](https://arxiv.org/abs/2608.05493) — 用声明式 Agent 编程自动学习 DSL 的上下文无关文法，使 LLM 在低资源 DSL 中通过文法约束解码生成语法正确的代码，对 LLM 驱动的编译器代码生成有直接应用价值。
- **PPDL: LLM 工作流即概率程序** — [arXiv](https://arxiv.org/abs/2608.05234)（同 §2）为 LLM 驱动代码生成/优化流程提供形式化可靠性基础。
- **LLM 微调驱动的混合 SSD 管理** — [arXiv](https://arxiv.org/abs/2503.13105) 用微调 LLM 优化 SLC/QLC 闪存模式切换与数据放置——LLM 用于系统优化的典型案例。

## 8️⃣ 边缘与端侧推理

- **EdgeXpert: 边缘设备 MoE + 推测解码联合优化** — [arXiv](https://arxiv.org/abs/2608.05303) 结合 MoE（减少 FFN 外部内存访问）和推测解码（减少解码轮次），直击端侧 LLM 推理的内存带宽瓶颈。
- **OBASE: 基于对象地址空间工程的内存分级优化** — [arXiv](https://arxiv.org/abs/2603.00378) 发现传统分配器按大小而非冷热程度放置对象，导致热对象将冷数据拖入昂贵 DRAM；提出对象级地址空间重构，对端侧内存受限场景有重要意义。
