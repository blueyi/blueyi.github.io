# 📡 AI Infra 日报 · 2026-08-11（周二）

> 覆盖窗口：2026-08-10 ~ 2026-08-11 · 信息源：Hacker News / arXiv

## 1️⃣ AI 芯片

- [FP4 Tensor Core 上模拟 FP64 矩阵乘法](https://arxiv.org/abs/2608.06812)：提出基于 Ozaki Scheme I/II 的方法，在 E2M1 格式的 FP4 Tensor Core 上实现双精度 DGEMM。此前同类工作停留在 INT8/FP8，首次将高精度计算下沉到 FP4 硬件，对低精度计算单元的潜力挖掘有重要参考价值。
- [G-Power：架构级 GPU 功耗建模](https://arxiv.org/abs/2608.06870)：利用已知 GPU 的聚合知识基础构建新 GPU 的功耗模型，解决功耗标签采集耗时的问题，面向现代 GPU 功耗优化设计。
- [NPU-PIM 统一内存重思考](https://arxiv.org/abs/2608.06989)：针对 NPU+PIM 异构架构的 LLM 推理，提出双视图内存设计，打破传统静态设备绑定假设，实现动态推理下的数据共享优化。
- [双节点 DGX Spark 分布式训练验证](https://arxiv.org/abs/2608.07226)：在两台 NVIDIA DGX Spark（GB10 Grace Blackwell、128GB 统一内存）上通过 Tailscale 组网，完成分布式 NanoChat 预训练的概念验证，验证了桌面级加速器多节点训练的可行性。

## 2️⃣ AI 编译器与框架

- [StateFlow：面向长上下文的序列流水线并行](https://arxiv.org/abs/2608.06838)：针对线性注意力和状态空间模型等循环/混合架构，提出序列流水线并行系统，解决长序列训练中的高效并行化挑战，对 Mamba、RWKV 类模型的分布式训练有实践意义。

## 3️⃣ AI 推理优化（数据中心）

- [Cascade：SLO 感知的 LLM 推理调度](https://arxiv.org/abs/2608.06557)：现代 LLM 请求从短交互到长推理链跨度极大，Cascade 利用 SLO 感知的延迟预算实现公平且高吞吐的推理服务，兼容 reasoning/agentic 类长请求场景。
- [SNI-GNN：SmartNIC 辅助全图 GNN 训练](https://arxiv.org/abs/2608.06441)（交叉引用自 Cat 4）：在 SmartNIC 上部署轻量线性趋势预测器，以网内嵌入预测减少跨节点通信，对大规模图训练的网络瓶颈缓解有启发。

## 4️⃣ 数据中心与基础设施

- [Snowflake：如何将 CDC 推入 Postgres](https://www.snowflake.com/en/blog/engineering/postgres-to-snowflake-replication-mirroring/)（HN 139 分）：详解 Snowflake 工程团队如何实现 Postgres 到 Snowflake 的实时复制镜像，涉及 CDC 在数据库层面的深度集成。
- [MARS：基于 MCTS 的自适应调度器](https://arxiv.org/abs/2608.06629)：针对 HPC 系统的作业调度与预留管理，用蒙特卡洛树搜索替代静态启发式，避免 DRL 方法需历史训练数据且目标固化的问题，调度策略可随优先级变化动态调整。
- [Kubernetes 调度器插件实现集群级放置优化](https://arxiv.org/abs/2608.06987)：K8s 默认调度器使用快速局部决策导致资源碎片化，该工作提出集群级全局放置计划的外部求解器与执行机制。
- [云边连续体自适应 CEP 框架](https://arxiv.org/abs/2608.06966)：面向云边协同的复杂事件处理系统，支持算子图在云边之间动态分布与自适应扩展。

## 5️⃣ AI 安全与治理

- [OpenAI 致德州州长：负责任 AI 基础设施](https://openai.com/index/responsible-ai-infrastructure-texas/)（HN 85 分）：OpenAI 就德州 AI 基础设施建设发表公开信，涉及能源、水资源与环境影响的政策承诺，是 AI 企业与地方政府博弈的典型案例。
- [GPT 5.6 Cyber：扩展 Daybreak 网络防御窗口](https://openai.com/index/expanding-daybreak-as-the-cyber-defense-window-narrows/)（HN 60 分）：OpenAI 发布面向网络安全的 GPT 5.6 Cyber，标志着 LLM 能力向专业安全领域的实质性渗透。
- [Anthropic：深入理解 Claude 的数学能力](https://www.anthropic.com/research/riemann-zeta)（HN 157 分）：通过 Riemann Zeta 函数等高等数学基准测试，系统性评估 Claude 的数学推理边界，为模型能力透明化提供方法论。
- [探索 Claude/GPT 知识截止与预训练时间线](https://blog.sshh.io/p/exploring-claudegpt-knowledge-cutoffs)（HN 92 分）：第三方研究者通过实验推断各模型的知识截止日期与预训练数据时间窗口，揭示了模型知识边界评估的社区实践。
- [Latent Fact-Checking：通过激活工程检测虚假信息](https://arxiv.org/abs/2608.06417)：将真实性视为 LLM 表示空间的几何属性，提出基于激活工程的虚假信息检测框架，避开传统依赖外部知识检索的路径。
- [Sharding 防止 LLM 监督失效与对抗利用](https://arxiv.org/abs/2608.06422)：实验表明单次 LLM 调用判断多项要求时判别质量下降，将任务分片到多个独立调用可显著提升专家一致性，对 LLM-as-Judge 的工程实践有直接指导。

## 6️⃣ 具身智能

- [自适应 VLA 推理框架：环境感知模型选择](https://arxiv.org/abs/2608.06434)：针对双系统 VLA 架构中快慢模块耦合过紧的问题，提出环境感知的动态模型选择策略，平衡长时推理与实时闭环响应。
- [CrossTracer：跨具身导航的 VLA 推理与轨迹残差适配](https://arxiv.org/abs/2608.06688)：VLA 模型提供强语义先验但忽略不同机器人的运动学约束，CrossTracer 通过轨迹残差适配实现跨具身导航规划的泛化。
- [LyEvO：基于李雅普诺夫引导的 Sim-to-Real 安全优化](https://arxiv.org/abs/2608.06481)：将约束进化优化与统计模型检验结合，利用李雅普诺夫稳定性分析评估仿真策略的部署就绪度，聚焦 sim-to-real 的安全性难题。
- [SoRoMoX：JAX 实现的快速可微软体机器人模型](https://arxiv.org/abs/2608.06650)：将 Cosserat 杆理论的降阶模型用 JAX 重实现，支持可微、GPU 并行、面向控制的软体机器人建模范式，填补了软体机器人领域缺少与刚体机器人同等级工具链的空白。
- [SyncSBC：去中心化集群行为预测同步控制](https://arxiv.org/abs/2608.06587)：机器人集群中 agent 仅凭局部感知推断集群级行为，用于故障检测和行为变化识别。
- [RAVEN II 手术机器人受力驱动研究](https://arxiv.org/abs/2608.06488)：利用并行电机-缆绳单元对手术机器人施加可控外力，为基于学习的无传感器力估计提供高质量训练数据采集方案。
- [Hoverflie：旋翼护罩将微型无人机变为多模态气垫船](https://arxiv.org/abs/2608.06707)：为 Crazyflie 2.1 设计定制护罩系统，使其可切换为高效气垫船或自由飞行无人机，显著延长室内作业续航。

## 7️⃣ AI 自动算子与代码生成优化

- [HLSmith：专家引导的 C/C++ 到 HLS 翻译 Agent](https://arxiv.org/abs/2608.06791)：提出 Agent 框架将 C/C++ 代码自动翻译为高质量 HLS（高层次综合），辅助 FPGA 加速器开发，降低硬件设计门槛。
- [Agentic Planning for Symbolic Execution](https://arxiv.org/abs/2608.06397)：研究如何通过 Agent 推理改进符号执行工具的跨运行策略选择，在不改变底层引擎的前提下扩展其实用覆盖范围，为 LLM 辅助程序分析开辟新路径。

## 8️⃣ 边缘与端侧推理

- [Needle2：14MB 端侧 Agent LLM](https://cactuscompute.com/needle)（HN 130 分）：面向手机、可穿戴设备、智能家居和机器人的 14MB agentic LLM，展示了端侧大模型在极小内存预算下实现 agent 推理能力的进展。
- [面向实时线段检测的低延迟 ASIC 架构](https://arxiv.org/abs/2608.06439)：为嵌入式视觉场景（自主导航、VSLAM、工业检测）设计的硬件加速器，在资源受限平台上实现确定性低延迟，区别于深度学习方案的高资源消耗与经典算法的内容依赖延迟。
