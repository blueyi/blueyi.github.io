## 1️⃣ AI 芯片

- **AMD EPYC 9006「Venice」正式发布,Zen 6 把服务器 CPU 拉到 256 核** 🔥:Zen 6 架构代号 Venice 的 EPYC 9006 全面登场,最高 256 核、频率上探 5.3 GHz,IPC 提升 20%~31%(不同 SKU 取舍不同)。Tom's Hardware 实测双路 EPYC 9996(1024 线程)代际性能提升最高 93%,单路 9686F 在部分项目上压过 NVIDIA Vera;停更三年的 Epyc-X 线回归,Venice-X 面向 EDA/HPC,另有面向 GPU 供数的 Verano 超级芯片首次披露。这意味着通用 CPU 厂商正把"为加速器供数"当成一级设计目标,而不是被动配套。[来源](https://www.servethehome.com/amd-epyc-9006-results-are-here-and-amd-delivers-a-knockout-part-deux/)
- **Google TPU 8tx / TPU 8i Max:主机侧换 AMD Turin,推理带宽翻倍** 🔥:新一代 TPU 8tx 采用 AMD EPYC Turin 作为 host 并引入机密计算,TPU 8i Max 则把内存带宽直接翻倍,明确瞄准推理负载;The Next Platform 的判断是 Google 正在"重构 TPU 的产品形态以覆盖更宽的 AI 推理场景",而非只服务训练。对云厂商而言,这是把自研 ASIC 从"训练专用"推向"推理主力"的关键一步,也侧面印证 host CPU 与加速器的配比正在被重新设计。[来源](https://www.servethehome.com/google-tpu-8tx-8i-max-amd-epyc-turin/)
- **Infineon 造出全球首片 300 mm 功率碳化硅(SiC)晶圆**:功率器件从 200 mm 走向 300 mm,单片可产出芯片数量显著上升,直接对应 AI 数据中心供电链(PSU、48V 母线、UPS)的成本与产能瓶颈。AI 机架的瓶颈已从算力芯片蔓延到供电与散热器件,SiC 大尺寸化是这条链上少见的硬进展。[来源](https://www.infineon.com/press-release/2026/infpr202611-028)
- **传闻:英伟达可能放缓向台积电下单**:台湾《工商时报》援引未具名供应链消息称 NVIDIA 正放缓对台积电的芯片下单节奏,但未指明产品、制程、订单规模与时间表,NVIDIA 与台积电均未回应。单一信源,应视为传闻;若成立,通常对应库存周期与下一代平台切换窗口,而非需求崩塌。[来源](https://www.cnbeta.com.tw/articles/tech/1585852.htm)

## 2️⃣ AI 编译器与框架

- **NVIDIA OpenShell 成为 Agent 安全运行时的事实候选**:现代汽车集团正在验证 NVIDIA NemoClaw blueprint 与 OpenShell 运行时,AIM Intelligence 把 Starfort 平台与 OpenShell 集成以支撑安全的 Agentic AI。OpenShell 提供的是一层沙箱化的执行与隔离语义,属于"Agent 时代的 libc/runtime"位置——它决定上层编排框架能否安全地跑不可信代码。[来源](https://blogs.nvidia.com/blog/korea-secure-agentic-ai/)
- **微软 PDD Kit:把 Agent 生成的代码编译到可证明的规格上**:针对"AI 生成的代码量已超出人类逐行 review 能力"的现实,PDD Kit 把开发者意图转成 Verus 形式化规格,再证明 AI 生成的代码满足规格,已在全栈 Web 应用上验证。这是把编译器/验证器作为 AI 代码生成的"类型系统",与单纯的测试覆盖是两条不同路线。[来源](https://www.microsoft.com/en-us/research/blog/formally-verifying-agent-written-full-stack-web-apps-with-pdd-kit/)

## 3️⃣ AI 推理优化(数据中心)

- **NVIDIA Dynamo 为韩国四大开源模型出部署配方**:SK Telecom 的 A.X K2、LG AI Research 的 K-EXAONE 2.0、Upstage 的 Solar Open 2、Motif Technologies 的 Motif-3 均获得 Dynamo 优化的部署 recipe。核心矛盾被点得很清楚:模型规模已超出单卡容量,必须做多卡切分与 disaggregated 式调度,Dynamo 的作用是把"切分 + 路由 + KV 管理"从手写脚本变成可复用配置。这对非英语语种开源模型落地生产是最实际的推力。[来源](https://blogs.nvidia.com/blog/nvidia-dynamo-korea-open-models/)
- **《An Open Field Guide to Inference Engineering》引发讨论**:ModelPlane 的这份指南系统梳理了推理工程的完整链路——从 roofline 与算术强度判断瓶颈,到 batch/并发调度、KV cache 布局、prefill-decode 分离、量化与投机解码的收益边界。它之所以在 HN 上被讨论,是因为社区长期缺一份"跨框架、不绑定厂商"的推理工程方法论,而不是又一篇 vLLM 调参技巧。[来源](https://docs.modelplane.ai/guides/inference-guide)
- **推理硬件侧的连带变化**:TPU 8i Max 把带宽翻倍、AMD Venice 为 agentic 负载调优,两者的共同指向是推理场景的"内存墙 + 长上下文 KV"已成主要矛盾(详见 1️⃣)。当带宽而非 FLOPs 成为约束,量化的边际收益会下降、分层 KV 与稀疏注意力类方案的价值上升。[来源](https://www.nextplatform.com/compute/2026/11/09/google-rejiggers-tpu-accelerators-for-broader-ai-inference-work/5308534)

## 7️⃣ AI 自动算子与代码生成优化

- **DeepMind 发布 AlphaProof Code,HN 559 分** 🔥:把自动定理证明能力落到代码/形式化层面,意味着"AI 生成的不只是能跑的代码,而是可被证明满足规格的代码"。这与 2️⃣ 的 Verus 路线形成呼应:自动生成 + 自动验证必须成对出现,否则生成速度会把 review 与测试彻底压垮。[来源](https://deepmind.google/blog/introducing-alphaproof-code/)
- **openJiuwen 首发 TTSE 经验学习框架,主打 Agent 自演进"双轨"**:核心主张是让每次任务执行沉淀为下一次的经验,而不是每次从零 prompt。这是把"自动调优"的对象从 kernel/编译参数扩展到 agent 自身的策略与工具使用模式,属于 LLM-driven optimization 在编排层的延伸。[来源](https://www.qbitai.com/2026/11/508998.html)
- **CodeRabbit 用 Codex 把交付量做到 20 倍**:官方案例称其用 OpenAI 模型治理与校验 AI 生成代码,并以 Codex 在同等工程团队规模下把软件交付量提升 20 倍。真正可迁移的经验是"治理层先行"——没有评审与验证基础设施,生成速度的提升只会转化为缺陷率。[来源](https://openai.com/index/coderabbit-codex-daybreak)

## 🌟 今日亮点

1. **通用 CPU 与自研 ASIC 同时"为供数与推理"重设架构**:AMD 用 Zen 6 Venice(256 核、5.3 GHz、IPC +20~31%)和 Verano 明确"为加速器供数"的设计目标,Google 则用 TPU 8tx(AMD Turin host + 机密计算)与 8i Max(带宽翻倍)把自研芯片推向推理主力。两侧同日发布,说明机架内的 CPU:加速器配比和内存带宽正被重新定义。

2. **Anthropic IPO 路演把 AI capex 送进公开市场审视**:拟发 8.25 亿股、区间 70~78 美元、估值最高约 1.4 万亿、募资约 640 亿美元,七位联合创始人合计套现约 17.5 亿美元且保留控制权。前沿实验室的融资结构从风投转向二级市场,意味着后续每一轮数据中心与算力承诺都要接受季度财报的检验。

3. **触觉成为具身智能的下一个"基础模型"模态**:蚂蚁灵波开源 LingBot-Touch,基于近 5000 小时真实触觉数据、覆盖三类传感路线,目标是跨硬件跨任务复用。这直接针对 VLA 最薄弱的一环——精细操作的数据无法靠视频规模化,触觉基础模型若成立,操作类任务的泛化成本结构会改变。

4. **资本在具身领域出现明显分层**:Path Robotics 以 3 亿美元 E 轮、24.5 亿美元投后估值聚焦制造业物理 AI,而 SoftBank 54 亿美元收购 ABB 机器人业务被中国否决。一边是高确定性工业场景获得大额后期资金,一边是跨境整合被产业安全审查挡住——具身的规模化路径更可能长在产线上,而不是靠并购拼图。

5. **"AI 生成代码"开始与"可证明正确"绑定**:DeepMind AlphaProof Code 把自动证明推进到代码层,微软 PDD Kit 用 Verus 形式化规格证明 Agent 生成的代码,CodeRabbit 则用治理层把交付量做到 20 倍。三件事指向同一结论:生成速度不再是瓶颈,验证带宽才是,自动生成与自动验证必须成对交付。
