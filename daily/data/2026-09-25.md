## 3️⃣ AI 推理优化(数据中心)

- **KV Cache 的"工作集":面向 LLM 推理系统的在线容量规划** 🔥:把 prefix cache 的 KV 驻留问题形式化为在线工作集规划——Agent 长会话 + 工具调用场景下,该保留多少 KV 才有收益,终于有了可算的模型。[arXiv 2609.27746](https://arxiv.org/abs/2609.27746)
- **Crossflow:面向 Agentic 服务的 Prefill–Decode 弹性** 🔥:P/D 分离的收益建立在静态切分上,但真实 fleet 里"未缓存输入 / 输出 token"比例存在明显峰值——把静态切分改成弹性调度。[arXiv 2609.27085](https://arxiv.org/abs/2609.27085)
- **CXL-SSD + 分块 KV Cache 管理**:NAND 做 prefix cache 的容量上限诱人,但块 I/O 路径带 CPU cache 争用与 host DRAM 中转,原生 CXL-SSD 也不够——需要 chunk-aware 管理才能吃到字节寻址。[arXiv 2609.26828](https://arxiv.org/abs/2609.26828)
- **MicroQonv:卷积张量重塑 + microscaling 量化**:避免"每个张量量化两次"的朴素做法,让 8bit 以下的 microscaling 在卷积层真正省下带宽。[arXiv 2609.28358](https://arxiv.org/abs/2609.28358)
