# 📡 AI Infra 日报 · 2026-07-21(周二)

> 覆盖窗口:2026-07-19 ~ 2026-07-21 · 信息源:Hacker News / arXiv

## 1️⃣ AI 芯片

- [RTL-Sequencer: 基于序列范式的可扩展 RTL 时序预测](https://arxiv.org/abs/2607.15830)(arXiv cs.AR)— 针对图神经网络方法感受野有限、复杂度高、缺乏信号方向性的痛点,提出通过 BFS 遍历将逻辑锥线性化的序列化范式,把 RTL 级时序预测变成可扩展的序列建模问题,是 EDA × ML 路线上的又一步。
- [Vogls: 面向流片前功耗侧信道分析的快速交互式全时序仿真器](https://arxiv.org/abs/2607.15782)(arXiv cs.AR)— 开源工具,专为侧信道分析所需的"大量短 trace、微小输入扰动"场景优化,填补了传统功能验证仿真器的空白。
- [ECC 降低嵌入式动态存储器(GCRAM)功耗](https://arxiv.org/abs/2607.16042)(arXiv cs.AR)— 用纠错码掩盖弱单元位错误、减少刷新频率,量化了额外访问/逻辑能耗与刷新节省之间的权衡,对片上高密度缓存设计有参考价值。
- [离线强化学习加速详细布线收敛](https://arxiv.org/abs/2512.03594)(arXiv cs.AR)— 用 offline RL 缩短物理设计中最耗时的 detailed routing 迭代次数,继布局之后 RL 进一步渗透后端流程。

## 2️⃣ AI 编译器与框架

- [Package Managers à la Carte: 依赖解析的形式化模型](https://arxiv.org/abs/2602.18602)(arXiv cs.PL)— 为碎片化的包管理器生态建立统一形式语义,对多语言 AI 工程(Python/C++/CUDA 混合依赖)的供应链可见性有长远意义。
- [Yarrow: 调和代数效应与基于区域的内存管理](https://arxiv.org/abs/2607.15876)(arXiv cs.PL)— 新 ML 系语言,解决 effect handler 非局部控制流破坏 region 栈式内存纪律的难题,是系统级语言设计(可类比 Mojo 的野心)的前沿探索。
- [双向类型检查:Freezing、Skeletons 与 Ghosts](https://arxiv.org/abs/2607.16061)(arXiv cs.PL)— 扩展双向类型系统支持混合信息流以推断一等多态,面向下一代编译器前端的类型推断基础设施。

## 3️⃣ AI 推理优化(数据中心)

- 🔥 [Every Microsecond Matters: GPU 集合通信逼近光速延迟](https://arxiv.org/abs/2607.16100)(arXiv cs.DC)— 指出长上下文、decode 密集的 LLM 推理已从带宽受限转向延迟受限:多 GPU 服务中大量小 collective 位于 token 生成关键路径上,每一微秒开销都直接影响吞吐。方向上与 NVLink/NVL72 时代的推理系统设计高度相关,值得推理框架团队精读。
- [DSTAR: 通过时空冗余消减加速 Diffusion Transformer](https://arxiv.org/abs/2607.15846)(arXiv cs.AR)— 现有 DiT 加速多只做相邻 timestep 的时间冗余,DSTAR 同时利用空间冗余,面向图像/视频生成推理的能效优化。
- [FSZ: 打破 GPU 有损压缩的预测-吞吐权衡](https://arxiv.org/abs/2607.15413)(arXiv cs.DC)— 重新设计预测阶段的三项算法创新,在保持纯 GPU 单 kernel 高吞吐的同时提升压缩率,可用于科学计算与大规模训练的数据搬运降本。
- [MCP 云端规模化:Scalable LLM Agent Tool Access in the Cloud](https://arxiv.org/abs/2607.15593)(arXiv cs.DC)— MCP 已成 Agent 工具调用事实标准,但云端大规模运营面临遗留服务接入与协议快速演进的兼容成本,论文给出系统化方案,Agent Infra 方向的信号值得关注。

- [JoyNexus: 面向 VLA 模型的服务化多租户后训练](https://arxiv.org/abs/2607.16074)(arXiv cs.DC)— 指出独占式 GPU 租赁/批作业模式对 VLA 后训练的资源浪费,提出多租户共享的后训练服务架构,机器人训练 Infra 化的信号。

## 5️⃣ AI 安全与治理

- 🔥 [Kimi K3、Qwen 3.8 与 Anthropic 的(潜在)瓦解](https://www.emergingtrajectories.com/lh/frontier-lab-economics/)(HN 272 分)— 热议前沿实验室经济学:中国开源模型(Kimi K3、Qwen 3.8)的快速迭代正在压缩闭源实验室的定价权与商业模式空间,文章直指 Anthropic 面临的结构性压力。开源-闭源竞争格局与实验室可持续性之争,是本期治理层面最重要的讨论。
- [量子程序生成必须优先保证有效性而非概率式 Scaling](https://arxiv.org/abs/2607.15313)(arXiv cs.LG,Position Paper)— 论证在有严格数学约束的领域(量子电路),盲目套用 scaling hypothesis 是方向性错误,对"生成即正确"的可验证 AI 生成范式有借鉴意义。
- [可迁移的阈值化可解释医疗分类框架](https://arxiv.org/abs/2607.15394)(arXiv cs.LG)— 黑盒模型阻碍医疗 AI 落地,提出统计学基础的全可解释规则分类方法。

## 6️⃣ 具身智能

## 7️⃣ AI 自动算子与代码生成优化

- 🔥 [LoRA Speedrun: 微调技术的公开 wall-clock 排行榜](https://github.com/Saivineeth147/lora-speedrun)(HN 138 分)— 效仿 nanoGPT speedrun 的思路,为 LoRA 微调建立公开的实测耗时榜单,把"炼丹技巧"变成可复现的竞速工程,预计将催生一波 kernel 级与训练配方级的自动优化提交。
- [From Patterns to Parsers: FPGA 高效硬件解析器自动生成](https://arxiv.org/abs/2607.16058)(arXiv cs.AR)— 开源工具,从高层规范经解析中间表示(PIR)自动生成优化的、人类可读的 SystemVerilog,自动 FSM 生成与字节对齐处理,属"规范→RTL"自动生成路线。
- [Gradual C0 等验证器中的 Unfolding 表达式与纯函数渐进验证](https://arxiv.org/abs/2607.15383)(arXiv cs.PL)— 提升演绎程序验证器规范的模块化能力,为自动生成代码的形式化验证铺路。
- [依赖动态类型的接地算术递归推理](https://arxiv.org/abs/2510.25369)(arXiv cs.PL)— 允许直接表达任意递归定义而不失一致性的形式推理基础,对程序合成的逻辑基座有潜在意义。

## 8️⃣ 边缘与端侧推理

- [在图处理器(IPU)上渲染 3D Gaussians](https://arxiv.org/abs/2607.15951)(arXiv cs.DC)— 首个在 Graphcore IPU(1472 个仅有片上 SRAM 的独立 tile)上实现的 3DGS 渲染器,其约束近似高效传感器-处理器架构,是低功耗端侧空间计算/机器人感知渲染的有趣探索。
- [Lazy Arithmetic + 脉动阵列:弥合嵌入式系统的验证鸿沟](https://arxiv.org/abs/2607.15328)(arXiv cs.AR)— 指出 GPU/NPU/TPU 为吞吐而非计算正确性设计,难以满足医疗设备等安全关键边缘场景,提出面向可验证正确性的脉动阵列惰性算术方案。
- [CoG 引导的权重校正:容错深度神经网络](https://arxiv.org/abs/2607.15753)(arXiv cs.AR)— 利用层内权重空间特征(重心)检测并恢复硬件/内存故障导致的权重损坏,面向安全关键嵌入式部署的可靠性加固。
- [qZACH-ViT: 量化感知的本征可解释医疗影像分类](https://arxiv.org/abs/2607.15421)(arXiv cs.LG)— 紧凑模型的量化效率与可解释证据一体化设计,适合资源受限的医疗边缘设备。
