3️⃣ AI 推理优化（数据中心）

  • HN109★非对称量化：97% 存储缩减下的近无损检索
    mixedbread 提出非对称量化方案，在检索场景实现约 97% 的存储压缩且几乎无损，对向量检索/RAG 的存储成本优化有直接价值。HN 109 分。
  • arXivHYPIC：位置无关缓存加速混合注意力 LLM 服务
    针对 RAG 与 agent 场景 prefill 阶段主导算力成本的问题，将位置无关 KV 缓存（PIC）与混合注意力模型结合，提升非连续共享片段的 KV 复用效率。
  • arXivLynx：渐进式投机量化加速长上下文 KV 传输
    在分离式（disaggregated）推理中，长上下文需跨网络传输大体量 KV 缓存并阻塞解码。Lynx 用渐进式投机量化减少数据量、缓解传输瓶颈。
  • arXiv面向分离式 LLM 服务的负载感知 Prefill 偏转
    分离式 serving 将 prefill 与 decode 分池，在突发重尾负载下 prefill 节点饱和而 decode 节点算力闲置。该工作提出负载感知的 prefill 偏转以平衡两池利用率。
  • arXivOmniPilot：异构 GPU 集群的不确定性感知推理顾问
    在共享异构 GPU 集群上服务 LLM 需提前选择 GPU 型号、张量并行度与精度。OmniPilot 用不确定性感知方法动态推荐配置，提升有效吞吐与启动成功率。
  • 一条命令在 HF Jobs 上跑起 vLLM 服务
    Hugging Face 放出在 HF Jobs 上一键部署 vLLM 推理服务的能力，降低了托管式大模型推理的运维门槛。
