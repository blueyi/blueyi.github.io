34 传感器·感知与本体感知（Proprioception）栈洞察

  • 章节编号:34
  • 所属层:A/H 交界(感知数据路径;驱动 06/09/21/25)
  • 关联 ADR:ADR-134(感知栈分层)、ADR-135(零拷贝传感路径)、ADR-136(多模态融合优先级)、ADR-137(触觉/力控 P1 路线)

1. 范围与目标​

定义 传感器→ISP→NPU 感知前端→VLA 输入 的端到端数据路径,补齐原 06 章「外设 IO」与 21 章「模型输入」之间的空白。

核心问题

  1. 具身量产需要哪些 传感 modality?优先级?
  2. 零拷贝路径(MIPI→dmabuf→ViT)如何对标 NITROS?
  3. 深度/IMU/力矩/触觉如何 tensor 化 进 VLA?

2. 需求洞察(按形态,见 33 章)​

Modality频率带宽压力VLA 用法章节
RGB 多相机30–60Hz高(6×1080p)ViT patch06 MIPI
深度/RGB-D30Hz中3D grasp;未来世界模型P1
IMU/里程计200Hz–1kHz低状态 token;控制35
关节力矩/位置1kHz低proprioception35
六维力/触觉100–500Hz低精细操作 P1P1
LiDAR(AMR)10–20Hz中导航;非 VLA 主路径Lite SKU

3. 业界方案对比(2025–2026)​

判断:量产须 NITROS 级零拷贝;LeRobot 路径仅开发态(26 双入口)。

3b. 感知→VLA 张量路径(候选)​

Camera MIPI → ISP (demosaic/NR) → dmabuf fd
 → IREE HAL import → ViT prefill (FP8/INT8)
 → 与 language/state token concat → VLM
Joint state (1kHz) → 降采样/插值 → state token @ 策略频率
Depth (optional) → 独立 encoder stub → fusion (P1)

延迟预算:传感+ISP 5–15ms(01 章);须纳入 27 章 E2E bench。

4. 候选方案​

候选小结
A. MIPI+dmabuf+单路 RGB P0;深度 P1;触觉 P2建议方案
B. USB 相机快速 demoM1 only
C. 全模态一次性覆盖范围爆炸

5. 多模态融合优先级(ADR-136)​

优先级能力Round
P0多路 RGB + proprioception(state)M3
P1深度/RGB-D + 时间同步M4
P2触觉/六维力 + 世界模型输入M5+

6. 结论与 ADR 候选​

  • ADR-134 感知栈分层:ISP/驱动(09)/中间件(25)/模型(21)接口 PerceptionTensorSet schema。
  • ADR-135 零拷贝路径:MIPI→dmabuf→HAL mandatory 量产;禁止 CPU bounce(09 反模式)。
  • ADR-136 多模态优先级:P0 RGB+state;P1 depth;P2 tactile —— 与 21 §3.7 对齐。
  • ADR-137 触觉/力控:精细操作场景(33)驱动;EtherCAT/Analog 进岛(06);VLA 输入 P1。
