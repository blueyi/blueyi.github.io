36 端→边→中心演进路线图洞察

  • 章节编号:36
  • 所属层:产品/平台(横切;汇总各章 §7)
  • 洞察轮次:Round 4(查缺补漏)
  • 状态:草稿 v1
  • 关联 ADR:ADR-139(三形态产品路线图)、ADR-140(边缘多租户架构)、ADR-141(中心推理服务边界)、ADR-142(互连与 SKU 演进)

1. 范围与目标​

将分散在各章的 端→边→中心 演进整合为 产品路线图,避免早期决策堵死未来路径(00 总纲目标 4)。

核心问题

  1. 三形态各自的 SKU/互连/软件栈 差异?
  2. 何时引入 Chiplet/HBM/PCIe 扩展?
  3. Fleet/多租户 在边缘/中心如何演进?

2. 三形态定义​

形态部署位置典型算力工作负载代表章节
端机器人本体Edge-Lite/Probatch=1 VLA;1kHz 岛01–25
边车间网关/边缘服务器Edge-Server共享 VLM;多 robot14/23/24
中心数据中心GPU/自研加速卡QAT/蒸馏;batch 推理;sim farm19/24/31

3. 演进时间线(候选)​

阶段产品形态硬件软件里程碑
Phase 1 (M1–M3)端 only单片 SoC Dev KitSDK V1.0;π0 E2E
Phase 2 (M4–M5)端量产Lite+Pro SKUOTA/Fleet;Model Zoo
Phase 3 (Y2–Y3)端+边Edge-Server;UCIe 可选(04/05)多租户 VLM;compile farm
Phase 4 (Y3+)端+边+中心HBM/Chiplet 边级中心 batch;数据湖(31)

不可逆点(汇总):07/08 ISA+ABI;06 岛 EtherCAT;22 bundle 格式 —— Tape-out 前冻结。

4. 形态间工作负载迁移​

工作负载端边中心
VLA 实时推理✅ 默认可选共享❌ 闭环
VLM prefill 大模型压缩版✅ FP8 共享全精度
QAT/蒸馏小 GPUfarm✅
OTA/provisioning接收中继管理
sim2real 数据采集缓冲训练

5. 互连与 SKU 演进(ADR-142)​

形态主存对外互连封装
端LPDDR5XMIPI;EtherCAT;GbE单片
边LPDDR/HBM 过渡PCIe/CXL;10GbE+单片→Chiplet 可选
中心HBMPCIe/CXL meshChiplet/MCM

6. 边缘多租户(ADR-140 候选)​

  • IREE multi-module + 容器隔离(14);每租户 VLM 实例;KV 分页(12/03)。
  • Fleet API(23)扩展 tenant_id;OTA 分轨。
  • 对标:NVIDIA Triton/Dynamo —— 我们 开放 IREE 路线。

7. 结论与 ADR 候选(待选型)​

  • ADR-139 三形态路线图(待选型):Phase 1–4 上表;与 lifecycle P0–P12 对齐。
  • ADR-140 边缘多租户(待选型):Edge-Server + multi-VM + Fleet tenant;Phase 3 启用。
  • ADR-141 中心推理边界(待选型):仅 非实时 batch + 训练;禁止 1kHz/VLA SLO(24 一致)。
  • ADR-142 互连/SKU 演进(待选型):端 LPDDR 单片;边 UCIe/PCIe 预留;中心 HBM Chiplet(04/05)。
