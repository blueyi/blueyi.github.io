35 控制栈与 VLA 边界洞察

  • 章节编号:35
  • 所属层:A/S/R 交界(控制闭环;衔接 13/25/28)
  • 洞察轮次:Round 4(查缺补漏)
  • 状态:草稿 v1
  • 关联 ADR:ADR-135(控制栈分层与频率)、ADR-136(VLA→执行器接口)、ADR-137(WBC/MPC 部署域)、ADR-138(VLA 与功能安全边界)

1. 范围与目标​

厘清 VLA/策略层(软/准实时) 与 控制层(硬实时 1kHz) 的职责边界、数据接口与部署域(NPU vs 安全岛 vs CPU)。

核心问题

  1. Helix S0/S1 式分层如何 映射到我们的栈?
  2. WBC/MPC/伺服 跑在哪?与 π0 chunk 如何衔接?
  3. VLA 输出能否直连关节?功能安全红线?

2. 控制栈分层(业界对标)​

┌─────────────────────────────────────────┐
│ S2 认知 VLA/VLM (0.2–9Hz)     → NPU     │  21/12
├─────────────────────────────────────────┤
│ S1 视觉运动 / 轨迹 (50–200Hz) → NPU/CPU │  可选;Helix 200Hz
├─────────────────────────────────────────┤
│ S0 伺服/WBC/MPC (1kHz)          → 安全岛 │  13/10 Zephyr

3. VLA → 执行器数据路径​

阶段内容频率运行域
VLA 输出action chunk H×dim1–50HzNPU+IREE
轨迹/抓取规划MoveIt/自定义10–100HzCPU PREEMPT_RT
阻抗/力控六维力环500Hz–1kHz岛或实时 CPU
关节伺服PD/torque1kHzZephyr 岛

接口(ADR-136 候选): sensor_msgs/JointState + 自定义 ActionChunk ROS2 消息;与 LeRobot 动作格式 manifest 映射。

4. WBC/MPC 部署域对比​

候选延迟灵活性小结
A. 1kHz 全进安全岛;VLA 仅高层目标最优 WCET岛算力有限初步倾向候选(协作/人形)
B. PREEMPT_RT Linux 跑 1kHz中易开发初判不宜量产唯一路径
C. VLA 直接输出 torque @1kHz——需求红线:禁止 SIL 唯一输入(28)

5. RTC 与控制衔接​

  • π0 50Hz chunk + RTC:执行层 插值/跟踪 200Hz–1kHz(35 章);runtime 双缓冲(21/14)。
  • Training-Time RTC:减少 inpainting;控制层仍须 平滑 chunk 边界。

6. 结论与 ADR 候选(待选型)​

  • ADR-135 控制栈分层(待选型):Round 1 VLA+ros2_control+岛伺服;S1 视觉运动 Optional(M5)。
  • ADR-136 VLA→执行器接口(待选型):ActionChunk ROS2 类型;与 25 ros2_control 硬件接口 对接。
  • ADR-137 WBC/MPC 部署域(待选型):1kHz 默认 Zephyr 岛;轨迹规划 PREEMPT_RT CPU。
  • ADR-138 VLA/安规边界(待选型):VLA=QM;急停/watchdog 岛独立;supervisor 监控 VLA 输出范围(28 ADR-094)。
