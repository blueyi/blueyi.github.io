24 端云协同与伴随服务洞察

  • 章节编号:24
  • 所属层:D 部署与服务层(端→边→中心桥接;承接 23 Fleet、29 遥测)
  • 洞察轮次:Round 2
  • 负责人 / 评审人:SDK/云端工程师(主)+ AI 编译器架构师 + 数据工程师
  • 状态:草稿 v3(统一论证风格:调研→对比→待选型)
  • 关联 ADR:ADR-083(编译云与 CI farm)、ADR-084(模型/制品分发 CDN)、ADR-085(遥测与回流最小闭环)、ADR-086(远程推理与 π0 云路径边界)
  • 上游依赖:18(autotune farm)、20(compile)、22(bundle)、23(Fleet)、29(telemetry)

1. 范围与目标​

定义 云端/边缘如何支撑端侧:编译 farm、模型分发、telemetry 后端、field data 回流(31 章预研)。Round 2 建 最小伴随服务,非完整 MLOps 平台。

核心问题

  1. 哪些工作在云、哪些必须在端?
  2. autotune/compile farm 如何与 18 L2 Agent 衔接?
  3. π0 远程推理 vs Figure onboard 边界?
  4. 对标 NVIDIA NGC、LeRobot Hub、Physical Intelligence cloud?

论证风格:本章为设计前洞察,按 业界调研(§3) → 对比矩阵(§4) → 初步倾向(待选型,非定论)(§6) 展开;洞察阶段不锁定方案;正式决策见 ADR/选型矩阵。术语见 embodied-intelligence-glossary.md。

2. 需求洞察(具身驱动)​

场景端云分工
VLA 编译(18)云/边 farm;端仅 load vmfb
GR00T 级实时端侧 92ms;云不做闭环
模型下载CDN + 23 OTA
失败 rollout 视频边侧缓冲→云 (29/31)
QAT/蒸馏(19)小规模云 GPU;非训练集群

原则(01 章):1kHz 控制与 VLA chunk 默认本地;云做 compile、分发、analytics、OTA。

3.2 编译云(衔接 18 ADR-066)​

Developer push manifest → CI compile(ISS gate) → autotune farm(L1/L2)
    → signed bundle → CDN → 23 OTA → robot
  • ISS gate:MR 必过;硅后 nightly 回归。
  • L2 Agent:仅在 farm 跑;输出 spec PR,非端侧 LLM。

3.4 远程推理边界​

允许禁止
非实时 demo、teleop 辅助1kHz 闭环
超大 VLA 原型量产 GR00T 级 latency SLO

π0 RTC:远程时 delay 更大;runtime 须 Training-Time RTC 兼容(21)。

3.5 趋势​

  1. compile in cloud, run on edge——行业默认。
  2. Agent CI farm(30 章)与 compile farm 合一。
  3. field data 闭环 Round 3(31)。

4. 候选方案​

候选小结
A. 自建 compile farm + S3-compatible CDN + Fleet API初步倾向候选(M3+)
B. 纯 GitHub Actions + manual USBM1–M2
C. 全托管 SageMaker非主线

6. 结论与 ADR​

  1. 编译/autotune 在云/边 farm;端只跑 signed bundle。
  2. VLA 闭环默认本地;远程仅 demo/非 SLO。
  3. 最小 telemetry 喂 29/11/18。
  • ADR-083 编译云(待选型):ISS CI gate;autotune farm;L2 Agent 仅 farm。
  • ADR-084 制品分发(待选型):CDN + 23 OTA;bundle 签名;LeRobot Hub 可选镜像。
  • ADR-085 遥测最小闭环(待选型):chunk_ms/Hz/thermal/power → Fleet;无默认原始视频。
  • ADR-086 远程推理边界(待选型):禁止 1kHz 上云;远程须 RTC-aware;SLO 模型 local-only 标签。
